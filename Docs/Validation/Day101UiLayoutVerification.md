# 101일차 추가 UI 정렬 검증

검증일: 2026-10-21. 비교 기준: UI 정렬 수정 전 101일차 작업본. 통합 개발 기준 커밋: `860abb9`. Unity 6000.3.21f1.

---
## 원인과 수정

상태창·보스바·전투 로그 탭·카드 더미 버튼은 PNG 전체 영역을 Sprite로 사용하여 투명한 바깥 영역과 실제 프레임 영역이 달랐다. 글자는 RectTransform의 전체 영역을 기준으로 배치되어 보이는 테두리와 어긋났다. 세로형 보조 패널 역시 큰 좌우 여백을 포함한 상태로 가로 안내에 적용되어 프레임이 문구보다 좁게 표시되었다.

Day98UiSkin에서 해당 자산의 프레임 표시 영역을 지정했다. PNG 파일의 픽셀과 알파는 변경하지 않았다. 상태창의 비스듬한 모서리를 포함하도록 9-Slice 경계와 배율을 보정하고 실제 최종 배치를 담당하는 BattleHudLegacyLayoutFix에서 내부 여백을 조정했다.

보스 프레임은 중앙 보석이 가로로 늘어나지 않는 단순 Sprite를 사용한다. 상단 18 기준 단위 여백을 유지하며 패널 높이 112, 폭 680으로 이름과 HP 막대를 보석 아래의 서로 다른 영역에 배치했다. 긴 이름은 지정한 최소 글자 크기 안에서 자동 보정한다.

로그 탭은 높이를 36에서 44로 늘리고 펼침 패널도 같은 차이만큼 위로 이동해 4 기준 단위 간격을 유지한다. 카드 더미 버튼은 원본 원형과 모서리를 포함한 영역으로 표시한다.

## 검증 결과

| 검사 | 결과 |
|---|---|
| 실제 UI 수정 전 렌더 | 상태창·보스바·안내의 어긋남 재현 |
| 1920×1080·1464×797·1280×720·1280×1024 렌더 | 글자의 프레임 내부 표시와 상단 영역 간 간격 확인 |
| 좁은 화면의 긴 문구 렌더 | 강화형 보스 이름·HP 123/123·GOLD 999999·킹 배치 안내 표시 확인 |
| 전체 EditMode | 878개 통과·실패 0개 |
| 전체 PlayMode | 19개 통과·실패 0개 |

실제 런타임 UI 생성 함수와 최종 레이아웃 함수를 호출했다. 비교를 위해 독립 빈 씬에서 Canvas를 같은 논리 화면 크기의 WorldSpace로 전환하고 카메라로 렌더했다. 원본 게임 씬의 모델·카드와 합성한 게임 플레이 스크린샷은 아니며, 검증용 코드·이미지는 실제 프로젝트에 추가하지 않는다.

이번 추가 수정에서는 전체 테스트와 시각 렌더를 실행했다. Windows 실행 파일 재빌드와 전체 런 수동 완주는 수행하지 않았다. 기존 101일차의 빌드 성공 기록과 구분한다.
