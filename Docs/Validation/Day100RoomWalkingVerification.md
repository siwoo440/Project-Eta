## 검사 내용

- 실제 Input System W·F·F2·F4 입력과 숫자 선택 키 충돌 차단.
- 실제 CharacterController의 테이블·벽 정지와 바닥 접지.
- 의자 거리·높이 조건과 멀리서 앉기 거부.
- 의자 복귀 시 기존 시점·카메라 위치·커서 상태 복원.
- 대각선 이동 속도 정규화와 상하 시선 뒤집힘 차단.
- 실제 보드 입력 권한의 이동 중 차단·복귀 후 복원.
- 일시정지 중 위치 변경·앉기 차단.
- 상점 카메라 고정 중 구형 TableCameraRig 비활성 유지와 종료 복원.
- 이동 중 실제 보상 화면이 열릴 때 자동 좌석 복귀와 클릭 차단 해제.
- 독립 몸체·환경 충돌체와 정적 이동 참조의 종료 정리.
- 이동 충돌체가 기본 Physics.RaycastAll 결과에서 제외되는지 확인.

자동 키 입력 검사는 Input System의 수동 갱신·포커스 독립·Game View 전달 설정으로 실행하고 각 검사 뒤 이전 설정을 복원했다. 초기 자동 검사의 단발 키 누락은 검사 환경의 입력 프레임 처리에서 확인됐고, 제품 입력 코드는 정상 프레임 방식으로 유지했다.

기존 99일차 증원 검사는 초기 편성 Seed가 런마다 달라 시험 증원 칸을 점유할 수 있었다. 초기 편성이 없는 행으로 시험 증원 위치를 설정하고 기존 2/4턴·증원 횟수·중복 차단·저장 규칙 검증은 유지했다. 제품의 점유 칸 증원 처리 규칙은 변경하지 않았다.
