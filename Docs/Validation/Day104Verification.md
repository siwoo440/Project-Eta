# 104일차 검증 기록

2026-10-22 기준. Unity 6000.3.21f1의 분리 검증 프로젝트에서 실제 컴포넌트·UGUI·CharacterController·InputSystem을 사용했다. 원본 기준 커밋은 ecff67e33802db6c08f6344efe41cc20e6d94046이다.

마무리 요청에서도 전체 EditMode 995개·PlayMode 57개를 다시 실행해 모두 통과했다. 커밋 전 원본의 적용 파일 20개와 기존 추적 C# 508개를 검증 프로젝트와 해시 대조해 일치를 확인했다.

검증 작업 폴더의 Day104ValidationOutput에 XML·로그·렌더 PNG·Windows 빌드를 보관한다. 임시 Editor 렌더 코드·검증 전용 빌드 산출물은 제품 소스 적용 목록에서 제외한다.

---
## 실패를 먼저 확인한 항목

1. ContractRed.xml: 자동 조사 담당자 없는 상태에서 계약 검사 1개 실패.
2. FeatureRed.xml: 기본 대상 판정 이후 조사창·입력 연결 전 12개 중 9개 실패.
3. UiLifetimeRed.xml: UI 담당자를 비활성화해도 조사 모달이 남아 1개 실패. UI.OnDisable 정리와 비활성 UI 진입 거부 추가.
4. WalkerLifetimeRed.xml: 이동기만 제거했을 때 조사 담당자와 독립 월드 모델이 남아 1개 실패. 이동기 파괴 시 자동 조사 담당자 정리 추가.

각 구현·수정 후 마지막 전체 검사에서 모두 통과했다. 중간 하단 안내 검사는 실제 UI LateUpdate 전의 값을 읽어 실패했으며, 담당자의 실제 프레임 갱신 완료를 기다리도록 검사 대기 순서를 보정했다.

## 실제 동작 검사 범위

- 카메라 리그의 자동 연결, 네 고정 대상, 재설정 시 중복 생성 방지.
- 방 내부 접근 좌표, 실제 눈높이·조사 거리·시선, 먼 거리·반대 방향·비활성·실제 장애물의 조사 거부.
- 네 대상 모두에 실제 CharacterController 이동을 적용한 모델 관통 차단.
- F로 열기, 실제 조사 제목 표시, 같은 키 유지·같은 프레임 중복 호출 차단.
- 조사 중 실제 이동·시선 차단, 닫은 뒤 원래 걷기와 커서 정책 복원.
- 조사 위 Pause 유지와 뒤쪽 닫기 차단, Pause 닫은 뒤 같은 조사 유지.
- 의자 접근 F의 앉기 우선, 조사 중 강제 좌석 복귀.
- Activity와 외부 카메라 고정이 함께 있을 때 필수 선택 화면으로 복귀.
- 재조사 확인 이력 중복 방지, 금빛 단일 강조·실제 하단 F 안내·시선 이탈 해제.
- 조사 담당자·UI 비활성화와 이동기 단독 파괴의 모달·모델·화면 수명 정리.

기존 전체 회귀 검사도 함께 실행했다. 신규 조사는 정식 저장·재화·기물 획득을 변경하지 않는다.

## 렌더에서 확인·수정한 부분

- 기존 실제 방 생성기를 빈 검증 Battle 씬에서 실행하고 실제 선 눈높이와 대상 전면 위치로 렌더했다.
- 가까운 물체 뒤에 UGUI가 가려지지 않도록 검증용 ScreenSpaceCamera 변환의 평면 거리를 보정했다. 제품 Canvas는 기존 ScreenSpaceOverlay를 유지한다.
- 어두운 방에서 조사 테두리가 흐리게 보여 조명 영향을 받지 않는 밝은 금빛 전용 재질로 수정했다.
- 하단 안내 두 줄이 프레임과 가까워 패널 높이 112와 글자 여백 16을 적용했다.
- 최종 PNG에서 네 대상의 강조·중앙점·이름·안내와 조사창 제목·본문·닫기 버튼·하단 안내를 직접 확인했다.
- 실제 조사창은 기존 Day98 패널·버튼 이미지를 재사용하며 추가 이미지 생성이나 기존 이미지 교체는 없다.
