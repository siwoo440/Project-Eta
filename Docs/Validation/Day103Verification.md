## 실패 재현과 수정 근거

- **InitialRed.xml: 8개 실패.** 모달 아래 보드·행동 완료 입력, 가려진 이벤트 버튼, 숨긴 페이지 콜백, Pause 비활성화 후 시간 정지, Esc+W 동시 기립, 걷기 중 Pause의 즉시 커서 표시, 키보드 선택 미지원, 최대 배율 설정창 잘림을 재현했다.
- **FeatureGreen.xml: 7개 통과·1개 실패.** 남은 설정창은 첫 표시 프레임의 Canvas 배율 갱신 순서가 원인이었다. 렌더 직전 실제 영역에서도 맞춤을 수행해 보완했다.
- **MenuRewardRed.xml: 2개 실패.** 최대 배율의 메인 메뉴가 화면 밖에 나가고, Pause 아래 보상 카드 선택이 가능한 상태를 재현했다. 메인 메뉴 묶음 맞춤과 보상 입력 소유 검사를 적용했다.
- **ReviewRed.xml: 2개 실패.** 모달 게이팅 때문에 능력 버튼을 재생성하여 이전 포커스가 파괴되는 문제와 Shift+오른쪽이 역방향 이동하는 문제를 재현했다. 모달 중 기존 버튼을 보존하고 Shift 보정을 Tab에만 적용했다.
- **FusionRed.xml: 1개 실패.** 일시적 권한 차단을 턴 변경으로 판단해 실제 합성 모드가 종료되는 문제를 재현했다. 모달 중 UI 상태 갱신과 토글 입력을 차단해 선택을 유지했다.
- **ScaleLabelRed.xml: 1개 실패.** 최대 UI 배율 135%가 볼륨용 상한으로 100%로 표시되는 기존 오류를 실제 슬라이더로 재현했다. 정규화된 배율의 실제 값을 표시하도록 수정했다.
- **PlayModeVerified.xml: 신규 14개 포함 전체 40개 통과.** 위 재현 사례를 포함한다. 최종 전체 EditMode 995개와 Windows 개발 빌드도 통과했다.

## 실제 동작 검사

- 모달 아래 보드·카드 소환·행동 완료 권한 차단.
- Pause 아래 이벤트 버튼 실행 차단과 복귀 후 정상 실행.
- 숨김·재구성 전의 이벤트 객체로 새 페이지 효과를 실행하지 못하는지 확인.
- Pause 컴포넌트 비활성화 시 원래 0.25배 시간·입력 활성·하위 화면 복원.
- 실제 Esc+W 같은 입력 갱신에서 Pause가 먼저 열리고 기립하지 않음.
- 걷기 중 Pause 표시 즉시 커서 확보, 닫은 뒤 걷기·보드 차단 유지, 앉은 뒤 해제.
- Tab이 비활성 선택을 건너뛰고 Enter가 현재 포커스 한 번만 실행. 이전 포인터 선택이 있어도 기본 Submit과 중복 없음.
- 최대 UI 배율의 실제 설정·메인 메뉴 영역과 취소 후 저장 배율 복원.
- 실제 카드 보상이 Pause 아래에서 선택·확정되지 않고 복귀 후 지급 가능.
- 실제 대현자 능력 버튼이 Pause 중 파괴되지 않고 버튼·기물·키보드 선택 복원.
- 실제 합성 UI가 Pause 전의 활성 모드를 유지.
- Shift+방향키는 방향 의미 유지.

## 렌더 범위

실제 생성 코드를 사용해 Pause1280x720, Settings1280x720·1280x1024·1920x1080, Controls1280x720, Menu1280x720·1280x1024의 7개 화면을 UI 배율 135%로 렌더했다. 모든 지정 패널 모서리가 출력 화면 안에 있음을 코드로 검사하고 설정·메인 메뉴 이미지를 직접 확인했다. 설정은 실제 슬라이더 경로로 편집값·135% 문구·미리보기를 함께 반영했다.

독립 검증 씬의 실제 UGUI를 출력용 카메라에 연결하고, 에디터에서는 실제 CanvasScaler.Handle 및 맞춤 갱신 메서드를 호출한 결과다. 실제 플레이 씬 전체를 촬영하거나 사람이 타이틀부터 엔딩까지 완주한 결과는 아니다.

## 남은 실제 검수

전체 런의 반복 전환·난이도·시간, 실제 창 포커스·장치 연결 해제·초광폭 화면은 수동 검수가 남았다. 게임패드 전 과정·다국어·사용자 난이도 선택·별도 글자 배율 접근성은 이번 완료 범위가 아니다. 화면 맞춤은 버튼 접근을 우선하므로 공간이 부족하면 큰 배율도 패널 단위로 줄어든다.

빌드는 기존 `ProjectEta.EditorTools.Day97DifficultyValidationMenu.BuildWindowsDevelopment` 진입점을 사용한다. Day97은 도구 이름이며 이번 일차 번호가 아니다. 임시 렌더 도구·실행 파일·빌드 중 생성된 기존 보고서·설정 변경은 원본 적용 및 커밋에서 제외한다.
