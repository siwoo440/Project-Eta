# 103일차 화면·입력 정리

화면을 오가며 입력이 뒤로 전달되거나 원래 선택 상태가 사라지지 않도록 기존 흐름을 보완했다. 이번 일차는 전체 화면 구조를 새로 만드는 작업이 아니다.

---
## 개발 순서

1. **입력 우선순위:** 기존 Day69UiPresentationRules에 공통 판정을 추가했다. 모달·디버그·씬 전환·걷기 상태와 시스템 키 입력 프레임을 확인해 보드·지도·턴 완료·시점·걷기를 차단한다.
2. **모달 복원:** Pause를 걷기·보드보다 먼저 처리하고 원래 시간 배율·보드/지도 컴포넌트 활성·커서·UI 선택을 보관한다. 닫기·비활성화에서 복원하고 하위 설정/조작법의 뒤로가기는 Pause를 거친다.
3. **선택 화면:** 상점·이벤트는 현재 보이는 페이지의 콜백만 실행한다. Tab/방향키·Enter·Backspace를 연결하고 기본 Input Module의 Submit과 중복 실행되지 않게 분리했다. 보상은 상위 모달 아래에서 선택·확정을 받지 않는다.
4. **선택 보존:** 일시적 입력 차단이 실제 턴 변경으로 취급되어 능력 버튼이 파괴되거나 합성 모드가 해제되지 않게 했다. 원래 능력 버튼과 선택·합성 모드를 유지한다.
5. **화면 맞춤:** 설정·Pause·조작법 고정 패널과 메인 메뉴의 좌우 패널 묶음을 실제 부모 영역에 균일하게 맞춘다. 큰 UI 배율에서도 하단 버튼 접근을 우선한다. 135%를 100%로 제한해 표시하던 기존 문구도 실제 배율에 맞췄다.
6. **범위와 검증:** 현재 언어·게임패드·난이도·접근성 구현을 문서로 구분하고 실제 키/버튼·생명주기·렌더·전체 테스트·빌드로 검사했다.

---
## Unity에서 확인할 순서

1. 재생을 중지하고 컴파일·에셋 가져오기를 완료한다. 새 Inspector 연결은 없다.
2. 새 런 또는 이어하기로 전투·지도를 연다. Esc와 WASD를 함께 눌러 Pause가 먼저 열리고 의자에서 일어나지 않는지 확인한다.
3. 걷는 중 Esc를 눌러 커서가 보이고 이동이 멈추는지 확인한다. 닫으면 걷기를 유지하고 의자 근처 F로 앉으면 기존 HUD가 복원되는지 확인한다.
4. 상점·이벤트에서 Tab/Shift+Tab 또는 방향키로 활성 선택을 순환하고 Enter로 확인한다. 취소/뒤로/나가기 버튼이 있는 페이지에서 Backspace로 복귀한다. Esc는 필수 이벤트를 건너뛰지 않고 Pause를 연다.
5. 이벤트·보상 위에 Pause를 열고, 아래의 선택이 실행되지 않는지 확인한다. 닫은 뒤 정상 선택한다.
6. 능력 버튼을 선택하거나 합성 모드에 들어간 상태에서 Pause → 설정/조작법 → Pause → 게임을 반복한다. 기물·능력 버튼 포커스·합성 모드가 유지되는지 확인한다.
7. 설정 UI 배율을 최대로 올려 하단 적용/취소 버튼이 보이는지 확인한다. 취소하면 저장된 배율로 돌아간다. 해상도·화면 모드·적용 후 재진입도 확인한다.
8. 메인 메뉴의 좌우 패널과 Pause·설정을 1280×720·1920×1080·1280×1024에서 확인한다.

작은 화면에서는 큰 배율을 그대로 유지하면 버튼이 가려지므로 패널을 추가로 축소한다. 별도 글자 배율 접근성·완전한 게임패드 조작·언어 선택 기능을 추가한 것은 아니다.

---
## 104일차 방향

기존 WASD 이동을 실제 탐색으로 연결한다. 방의 접근 구역과 충돌을 정리하고 조사 가능한 물체·상호작용 거리·안내·조사창·테이블 복귀를 단계적으로 붙인다. 정식 핵심/선택 단서의 전체 콘텐츠와 영구 탐색 저장은 후속 범위로 분리한다.
