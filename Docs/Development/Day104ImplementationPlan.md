# 104일차 방 조사 구현 계획

**목표:** 기존 걷기 상태에서 가까운 물건을 바라보고 F로 조사하고 원래 탐색·좌석 상태로 복귀.
**실행:** 이 채팅에서 직접 구현·검증. 기존 검증 프로젝트 사용, 최종 해시 대조 후 F:/Project-Eta 적용. 이번 요청은 커밋·푸시 제외.
**사양:** Devlogs/Day103/README.md의 승인된 104일차 방향과 이번 대화의 범위. 기존 방에 4곳의 조사 대상을 자동 배치하고 문은 잠긴 상호작용까지만 구현.
**기술:** Unity 6000.3.21f1, C#, CharacterController, UGUI, 기존 런타임 생성 방식.

---
## 공통 제약

- 새 C# 각 줄의 짧은 한글 주석과 Allman 스타일.
- Inspector·씬·Prefab 수동 연결 없음. 기존 저장 포맷·게임 재화·전투·정식 단서 상태 변경 없음.
- 기존 103일차의 같은 프레임 입력 소비·Pause 우선순위·걷기 HUD 마스크 유지.
- F 우선순위: 상위 모달 → 열린 조사창 닫기 → 가까운 의자 앉기 → 바라보는 조사 대상.
- 닫힌 문은 조사 가능하되 이동 통로 개방과 후속 구역 진입은 아직 없음.
- 조사 확인 이력은 현재 방 인스턴스의 런타임 이력. 영구 저장·도감·핵심 단서가 아님.
