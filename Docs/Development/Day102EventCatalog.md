# 102일차 이벤트 목록

기획서 로그라이크 이벤트 탭의 EV01~EV35와 A·B·C를 실제 실행 데이터로 옮겼다. 비용·보상은 기획서 임시 수치다. 공통 10·페이즈 전용 14의 추첨 가중치는 구현 임시값이다.

보상·교환은 해금된 1성과 동일 기물 합산 최대 3개 제한을 적용한다. 정보는 선택 단서 후보 열람 이력이며 정식 단서 원문·진엔딩 조건과 분리한다.
