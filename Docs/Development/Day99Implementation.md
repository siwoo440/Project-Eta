# 99일차 스테이지 규칙과 보상 안내

일반·정예 전투의 차이를 실제 규칙으로 분리하고, 지도에 안내한 규칙을 전투와 Gold 지급에서 재사용하도록 연결.

---
## 적용 순서와 결과

| 단계 | 적용 내용 |
|---|---|
| 1 | 일반 30턴·3/5턴 증원 유지, 정예 전용 EliteRound99에 임시 25턴·2/4턴 증원 설정 |
| 2 | 페이즈+스테이지 정의별 규칙을 RunBalanceData에 저장, 실제 전투에는 독립 라운드 복제 적용 |
| 3 | 지도 상세에 제한·증원·Gold·실제 카드 정책과 접근 상태 표시 |
| 4 | 보상 제목을 실제 1성 선택 정책으로 수정, 상점에 미해금 수 안내 |
| 5 | F1 상태 탭에 스테이지 규칙·보상과 후보 제외 사유 추가 |
| 6 | 저장·Gold 중복 지급·현재 런 해금 고정·사망 포함 상한·실제 증원 동작 검사 |
| 7 | 지도 이미지의 투명 여백을 Sprite 표시 영역에서 제외, 보상 제목·상점 두 줄 안내 잘림 수정 |

---
## 생성·수정·삭제

생성: 규칙 저장/조회 서비스, 지도 안내 작성기, 후보 제외 사유 판정기, 정예 라운드 에셋, 자동 표본 메뉴, EditMode·PlayMode 검사.

수정: 라운드 설정 API, 스테이지 카탈로그, 런 저장 데이터, 전투 적용과 Gold 지급, 카드 후보 생성, 지도·보상·상점·F1 화면, 지도 이미지 표시 영역. 기존 59일차 소스 문자열 검사를 실제 후보 동작 검사로 교체.

원본 프로젝트 파일 삭제 없음. 화면 검증용 임시 코드는 검증 복사본에서 제거.

---
## 규칙과 보상

| 항목 | 일반 | 정예 |
|---|---:|---:|
| 제한 턴 | 30 | 25 |
| 라운드 증원 | 3·5턴 | 2·4턴 |
| 첫 페이즈 승리 Gold | 15 | 25 |
| 이후 페이즈 Gold 가산 | 페이즈마다 +5 | 페이즈마다 +5 |
| 카드 직접 획득 | 1성 후보 중 1장 | 1성 후보 중 1장 |

정예 제한과 증원 시점은 실측 전 임시값. 기존 Seed 편성 원형과 보스 패턴 유지.
2~5성 기물은 합성으로 획득. 최종 보스 승리 후에는 카드 보상 없이 런 종료.
기존 런의 미해금 후보는 영구 해금 후에도 제외되고, 다음 런부터 후보에 포함.
보유 상한에는 정상 카드와 사망 카드가 모두 포함.

---
## 이어하기

규칙을 한 번 조회한 스테이지는 제한 턴·시작 적·증원·보스 배치·승리 Gold를 저장.
설정 에셋을 이후 변경해도 저장된 해당 런 규칙은 유지.
아직 조회하지 않은 스테이지는 최초 조회 시점의 설정을 저장.
새 필드가 없는 구버전 저장은 최초 조회 시 현행 규칙으로 채움. 저장되지 않았던 과거 규칙까지 복구하는 기능은 없음.
기존 Gold 지급 이력과 경제·난이도 기록 유지.

## Unity에서 확인할 순서

1. F:\Project-Eta 프로젝트를 Unity에서 열고 스크립트·리소스 재임포트 완료 확인.
2. 지도에서 정예 노드에 마우스를 올려 제한 25턴·증원 2/4턴·Gold 안내 확인.
3. 정예 전투에서 F1 → 상태 → 스테이지 규칙·보상 확인.
4. F1 → 콘텐츠 해금·획득 제한 → 제외 후보와 사유 펼치기에서 잠금·합성·보유 상한 확인.
5. 상점 카드 구매 화면의 미해금 제외 수와 1성 정책 확인.
6. 안전 지점 저장 후 이어하기에서 규칙과 보상 중복 지급 차단 확인.
7. 전체 런 3회 이상을 실제 플레이하고 F1 → 상태 → 측정 JSON / CSV 저장으로 종료 턴·왕 HP 손실 수집.

씬·Prefab·Inspector에서 직접 연결하거나 수정할 파일 없음.
자동 보고서는 Project Eta → Day 99 → Generate Stage Rules Report 메뉴로 재생성.
기본 저장 위치: Docs/Validation/Day99StageRuleSampling.md.
플레이 기록 저장 위치: Application.persistentDataPath/BalanceReports. 저장 성공 시 Unity Console에 실제 경로 출력.
