# 104일차 방 조사 구현

기존 WASD 방 이동에 물건 조사 흐름을 연결했다. 별도 Inspector·씬·Prefab 연결 없이 기존 좌석 카메라가 조사 대상 4곳과 화면을 자동 생성한다.

---
## 개발 단계

1. 방 가장자리에 조사 대상의 데이터·임시 모델·이동 충돌체 배치.
2. 거리·바라보기·실제 Collider 가림을 통과한 대상에 금빛 테두리와 하단 F 안내 표시.
3. F 조사창과 기존 입력 소유 규칙 연결. 조사 중 이동·시선 차단, 닫은 뒤 복원.
4. Pause 중첩·의자 복귀·필수 화면·비활성화·파괴의 소유 해제와 전체 회귀 검증.

---
## 대상과 배치

위치는 기존 방의 월드 좌표이며 높이는 방 바닥 기준이다. 모델과 문구는 기초 동작 확인용이다.

| 고정 ID | 대상 | 위치 X / Z | 전면 방향 |
|---|---|---|---|
| room_records | 기록대 | -12 / -5 | 동쪽 |
| room_shelf | 기물 진열대 | 12.3 / 0 | 서쪽 |
| room_wall | 벽의 금속 장식 | 9.5 / 16.5 | 남쪽 |
| room_door | 잠긴 출입문 | 9.5 / -17.6 | 북쪽 |

- 공통 조사 거리 4.5, 바라보기 내적 0.86 이상. 실제 눈높이에서 대상 앞면까지 검사.
- 방 벽·테이블·다른 대상에 가려지면 조사 불가. 플레이어 CharacterController 자체는 시선 검사에서 제외.
- 루트 BoxCollider로 걷기 관통 차단. 시각 도형의 기본 Collider는 제거.
- layer 2로 기존 보드 클릭 레이에서 제외하되 조사 전용 레이에는 포함.
- 조사 가능한 물체를 바라볼 때만 금빛 테두리·중앙 조준점·하단 대상 이름 표시.

## 조작과 복원

| 상황 | 동작 |
|---|---|
| 좌석에서 WASD | 기존 방식으로 기립 |
| 가까운 대상 바라보기 + F | 조사창 열기 |
| 조사창에서 F / Enter / 숫자패드 Enter / Backspace | 조사창 닫기 |
| 조사창의 닫기 버튼 클릭 | 조사창 닫기 |
| 조사창에서 일시정지 키 | 기존 Pause를 위에 표시 |
| 가까운 의자에서 F | 조사보다 앉기 우선 |
| 보상·활동·결과·튜토리얼 필수 화면 | 조사 정리 후 좌석 복귀 |

열기·닫기 프레임의 입력은 공통 규칙에서 소비한다. 키를 누른 채 유지해도 조사창을 반복해서 열고 닫지 않는다. Pause 중에는 뒤쪽 조사창을 닫거나 움직일 수 없다. 조사창 자체는 게임 시간을 멈추지 않으며 이동·시선 입력을 막는다.

조사 확인 이력은 현재 조사 담당자 인스턴스의 HashSet이며 재조사 시 중복 집계하지 않는다. 화면·이동기·호스트가 제거되면 모달·커서·독립 모델·전용 재질을 정리한다.

## Unity에서 확인할 순서

1. 재생을 중지하고 스크립트 컴파일 완료를 기다린다. 수동 코드 수정이나 Inspector 연결은 없다.
2. 기존 Battle 진행에서 WASD로 일어나 서쪽 기록대 또는 동쪽 기물 진열대에 접근한다.
3. 가까이서 대상을 바라보고 금빛 테두리·대상 이름을 확인한 뒤 F로 조사한다.
4. F·Enter·Backspace·닫기 버튼으로 닫고 이동과 마우스 시선이 복원되는지 확인한다.
5. 조사 중 Esc로 Pause를 열었다 닫아 조사창이 유지되는지 확인한다.
6. 남쪽 잠긴 문과 북쪽 금속 장식도 확인하고 의자 근처에서 F로 앉는다.

## 현재 범위와 한계

- 정식 핵심 8단서·선택 단서·영구 저장·도감·보상·구역 개방 조건은 이번 구현에 포함하지 않는다.
- 출입문은 잠긴 상태의 조사만 제공하며 열리지 않는다.
- 방 전체를 안내하는 지도·퀘스트 표시와 최종 제품 모델·서사 문구는 후속 작업이다.
- 고정 조사 F키는 기존 의자 조작과 같다. 일시정지 키를 F로 변경하면 상위 Pause 입력이 우선한다.
- 독립 렌더·자동 검사는 실제 전체 런 완주와 사람의 연속 탐색 검수를 대체하지 않는다.
