# 101일차 보스 데이터

[현재 기획서](https://docs.google.com/document/d/1kjDKNNy9T0lNyxoRq7SGl3w7RSzAJpKSlgWFHQYO2gE/edit?usp=sharing)의 보스 정체성·후보 페이즈·크기를 기준으로 데이터화했다.

HP·ATK·강화 수치는 기획서 확정값이 아닌 이번 구현의 임시 테스트값이다. 전용 행동 설명은 후속 구현용 사양이며 현재 AI가 실행하지 않는다.

## 전용 패턴 후속 사양 — 미구현

| 보스 | 계획된 이동 | 계획된 특수 행동 | 계획된 강화 특징 |
|---|---|---|---|
| 철문 골렘 바르가스 | 느린 직선 이동 | 한 턴 예고 십자 강타 | 성문 잔해 칸 봉쇄·기본 기물 증원 |
| 맹세의 기사 세르딘 | 인접 이동과 주기적 나이트 도약 | 도약 공격 예고 | 주변 병사 공격 지휘 |
| 성벽 거인 브라곤 | 짧은 상하좌우 이동 | 행·열 내려치기 예고 | 성벽 조각 장애물 |
| 폭풍 그리폰 카엘리스 | 넓은 도약 | 착지 지점 예고 | 연속 도약·폭풍 지형 |
| 월광 와이번 네르바 | 대각선 장거리 도약 | 착지 후 인접 공격 | 착지 후보 두 곳 예고 후 급습 |
| 질풍 켄타우로스 라우렌 | 직선 돌진·기병 도약 교대 | 돌진 경로 예고 | 기마병 증원 |
| 녹월의 역병술사 모르비아 | 직선·대각선 원거리 이동 | 독 중심 원거리 예고 공격 | 독 안개 위험 칸·상태 이상 증원 |
| 재의 리치 벨카르 | 장거리 마법 이동 | 화상 공격·불꽃 망령 소환 | 예고 범위 연속 화염 |
| 독안개 히드라 세르파나 | 여러 방향 짧은 원거리 이동 | 독·속박 교대 공격 | 머리별 위험 칸 예고 |
| 황금갑의 장군 아르카인 | 퀸 장거리·기병 도약 | 정예 공격 지휘 | HP 구간 이동 변화·왕 집중 지휘 |
| 거울 대공 세베리온 | 기병·비숍·룩 형태 순환 | 다음 형태 사전 표시 | 형태 전환별 예고 공격 |
| 성흔 대주교 엘레시아 | 대각선 장거리 이동 | 원거리 공격·정예 회복 교대 | 강화 대상·위험 칸 동시 예고 |
| 별먹는 고룡 아스트라곤 | 제한적인 전장 규칙 변경 | 한 턴 전 행·열 봉쇄 예고 | 증원 위치 변경 |
| 황혼의 흑왕 모르드레인 | 직선 압박·도약형 기동 | 상태 이상·증원·칸 봉쇄 순차 예고 | HP 50% 이하 패턴 조합 전환 |
| 마스터 킹 | 규칙 봉인 목표 중심 | 사전 예고형 규칙 변경 | 봉인 3개 면역·순차 해제 |

현재 15종은 기존 공통 보스 패턴과 공통 외형을 사용한다. `provisional=true`, `bespokePatternsImplemented=false`로 임시 수치와 전용 패턴 미구현 상태를 명시했다.

## 저장 기준

처음 스테이지 규칙을 조회할 때 선택 결과·형태·최대 HP·ATK·크기·면역·원형 경로·후속 사양 문자열을 독립 값으로 보관한다. 안전 체크포인트의 런 저장·복원에서 이 결과를 유지한다. 전투 보드 JSON 복원 지원과 전투 중 자동 이어하기 지원은 별개이며, 후자는 이번 범위에 포함하지 않았다.
