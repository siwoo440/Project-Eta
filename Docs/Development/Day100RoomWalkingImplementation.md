# 추가 100일차 : 의자에서 일어나 방 이동과 좌석 복귀

작성일: 2026-10-10. 기준 커밋: `a263462` — 99일차 정예 전투 규칙과 보상·해금 안내 연결.
적용 프로젝트: `F:\Project-Eta`.

---
## 적용 결과

기존 41일차 좌석 카메라를 확장해 WASD 입력으로 의자에서 일어나고, 방 안을 이동한 뒤 플레이어 의자 가까이에서 F키로 다시 앉는 흐름을 연결했다. 기존 의자와 방 모델은 유지했다.

이번 기능은 같은 Battle 공간의 이동 기능이다. 별도 탐색 구역·문·단서·스토리 진행은 후속 개발 대상이다.

---
## 조작

| 상태 | 입력 | 동작 |
|---|---|---|
| 앉은 상태 | WASD | 의자 오른쪽 바닥에서 일어나 입력 방향으로 이동 |
| 이동 중 | WASD | 바라보는 방향 기준 이동 |
| 이동 중 | 마우스 이동 | 좌우 자유 회전·상하 제한 회전 |
| 의자 가까이 | F | 이전에 선택한 좌석/보드 시점으로 복귀 |
| 앉은 상태 | F2 / F3 / F4 | 맨 위 / 기본 / 주변 둘러보기 시점 |
| F4 시점 | 마우스 우클릭 드래그 | 기존 앉은 상태 둘러보기 |
| 이동 중 | 일시정지 키 | 이동 중단·포인터 해제, 닫은 후 이동 재개 |

일시정지 기본 키는 Esc이며 저장된 변경 키를 안내에 표시한다. 숫자 1~0 손패 선택과 F1 디버그 패널은 유지한다. 기존 W/S 카메라 전환은 WASD 이동과 충돌하므로 실제 입력에서 제거했다.

---
## 이동과 복귀 규칙

- 이동 속도는 초당 4 월드 단위. 대각선 이동 속도 증가 차단.
- 의자 이탈 위치는 X 2.8, 바닥 Y+0.05, Z -10.7. 의자 내부에서 충돌 몸체가 생성되는 문제 방지.
- 이동 중 선 눈높이는 발 위치에서 5.25 단위. 현재 방·의자의 큰 모델 크기에 맞춘 임시 기준.
- 의자 중심으로 수평 3.4 단위 이내·같은 바닥 높이에서 F 복귀 허용.
- CharacterController와 전용 방·테이블·의자·상대 충돌체로 관통과 낙하 차단.
- 이동 충돌체는 Ignore Raycast 레이어를 사용해 기존 보드·지도 클릭 Raycast에서 제외.
- 이동 중 카메라는 충돌 몸체 위치를 직접 따라가며, 코너에서 카메라 보간이 장애물 안으로 들어가는 상황 방지.
- 이동 중 카드·배치·합성·보드 행동 완료·지도 선택·일반 UI 클릭 차단.
- 일시정지·F1 디버그 패널에서는 이동과 시선 입력 중단·포인터 해제.
- 보상·상점/이벤트·런 결과·튜토리얼이 열리면 자동 좌석 복귀로 필수 화면 입력 복원.
- 상점/이벤트 카메라 고정은 기존 TableCameraRig를 다시 켜지 않는 별도 시점 소유 방식으로 연결.
- 씬 종료·컴포넌트 비활성화 시 이동 상태·커서·생성 충돌체 정리.

이동 위치는 현재 런 저장 데이터에 추가하지 않았다. 저장을 다시 불러오면 기존 기본 좌석 시점에서 시작한다.

## Unity 확인 순서

1. `F:\Project-Eta` 프로젝트를 열고 스크립트 재임포트 완료 후 Battle 실행.
2. F4로 주변 둘러보기 시점을 선택하고 우클릭 드래그 확인.
3. WASD로 일어나 이동하고 마우스로 방 주변 확인.
4. 테이블·벽·의자 앞으로 이동해 관통 차단 확인.
5. 의자에서 멀리 F를 눌러 복귀가 거부되는지 확인.
6. 플레이어 의자에 접근해 `F : 의자에 앉기` 안내가 뜨면 F 입력.
7. F2/F3/F4 시점과 숫자 손패 선택, 앉은 뒤 보드·지도 조작 복원 확인.
8. 이동 중 일시정지·F1을 열고 이동 차단·포인터 사용·닫은 뒤 재개 확인.

자동 검사와 Windows 빌드 결과는 [검증 기록](../Validation/Day100RoomWalkingVerification.md)에 별도 기록한다. 전체 실제 플레이에서의 체감 속도·눈높이·방 가독성 검수는 별도다.
