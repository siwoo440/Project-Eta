# 101일차 구현 안내

페이즈별 보스의 정체성·수치·점유 크기를 저장 가능한 데이터로 연결하고, 걷기 속도와 이동 중 HUD 노출을 수정했다.

기준 커밋: `860abb9` — 100일차 : 의자 이탈 이동과 좌석 복귀 기능 추가. 검증일: 2026-10-21.

---
## 개발 단계

1. 기획서의 보스 15종을 개별 BossDefinition 에셋으로 등록.
2. 지도 Seed와 페이즈로 보스를 결정하고 기본형·강화형 결과를 스테이지 규칙에 보관.
3. 저장된 수치로 런타임 기물을 만들어 실제 보스 스폰·이름·체력·공격력·점유 칸에 연결.
4. 이동 속도·시간 처리 수정, 걷는 동안 게임 HUD의 표시와 클릭만 억제.
5. 자동 검사와 Windows 개발 빌드로 회귀 확인.

---
## 보스 선택과 복원

| 구간 | 적용 규칙 |
|---|---|
| 1~4페이즈 깊이 5 | 해당 페이즈 3종 중 기본형 1종 |
| 1~4페이즈 깊이 10 | 깊이 5와 다른 보스의 강화형 |
| 5페이즈 깊이 5 | 아스트라곤 고정 |
| 5페이즈 깊이 10 | 모르드레인 고정 |
| 마스터 킹 | 별도 데이터·미리보기만 제공, 실제 진엔딩 진입 미연결 |

같은 지도 Seed와 페이즈에서 조회 순서와 전역 난수에 관계없이 같은 보스를 선택한다. 선택 시점은 해당 스테이지 규칙을 처음 조회하거나 미리보기한 시점이다. 처음 기록된 보스 이름·수치·크기·면역을 스냅샷으로 저장하며, 이후 에셋 수치가 달라져도 저장된 결과를 사용한다.

기존 보스 선택 정보가 없는 유효한 스테이지 규칙은 재추첨하지 않고 이전 보스를 유지한다. 자동 이어하기는 기존 정책대로 지도 선택 전·보상·상점·이벤트 등의 안전 체크포인트만 지원한다. 전투 중 자동 이어하기 기능은 추가하지 않았다.

강화형은 임시 기준으로 체력 25% 증가(올림), 공격력 1 증가, 4턴 기본 폰 1개 추가 증원을 적용한다. 초기 배치·보스 점유 칸·기존 증원 칸과 겹치지 않는 위치를 선택한다.

## 실제 전투 범위

15종의 이름·페이즈·HP·ATK·1×1/2×2 크기·형태는 실제 전투에 반영된다. 원본 기물 에셋을 수정하지 않고 저장된 값의 런타임 복제본을 사용한다. 지도 미리보기와 F1 스테이지 규칙에 선택 정보와 공통 임시 패턴 상태를 표시한다.

현재 행동은 기존 공통 보스의 상하좌우 이동·근접 공격·2단계 예고 공격을 사용한다. 기획된 보스별 도약·독·화염·봉쇄·형태 전환·봉인, 전용 모델·애니메이션은 아직 구현하지 않았다. 모든 보스 수치는 임시이며 최종 밸런스가 아니다.

## 걷기와 UI 수정

- WASD 이동 속도: 실제 초당 4→8 월드 단위.
- 게임 저배속과 별도로 실제 경과 시간으로 이동, 일시정지 때는 기존대로 이동 차단.
- 긴 프레임의 시간을 버리지 않고 최대 0.05초 단위로 나눠 충돌 처리.
- 이동 중 손패·지도·보스 체력·전투 상태·합성·기물 정보 등 게임 HUD 숨김·클릭 차단.
- 이동 중 생성되는 HUD와 중첩 Canvas도 숨김 대상에 포함.
- 앉으면 전용 표시 마스크만 해제하고 원래 Canvas·Graphic·CanvasGroup 상태 유지.
- 걷기 안내·일시정지·F1·필수 진행 화면은 별도 처리 유지.
- 보상·상점·튜토리얼 등 필수 화면이 열리면 기존 규칙대로 자동 좌석 복귀.

HUD는 현재 게임 Canvas 이름을 기준으로 찾는다. 향후 다른 이름의 HUD를 추가할 때는 RoomWalkingHudVisibility의 대상 목록도 갱신해야 한다.

## Unity에서 따라 확인하기

1. Unity에서 에셋 가져오기와 컴파일이 끝날 때까지 대기.
2. 새 런 시작. 이미 기록된 기존 런 규칙은 이전 보스를 유지할 수 있음.
3. 지도에서 보스 미리보기, F1 스테이지 규칙에서 이름·형태·크기·수치 확인.
4. 보스 전투에서 이름·체력과 1×1/2×2 점유 확인.
5. WASD로 일어나 이동. 이동 안내 외 손패·지도·전투 HUD 숨김 확인.
6. 의자 근처에서 F로 앉은 뒤 HUD 복원 확인. F2/F3/F4 시점 선택과 Esc/F1 조작도 확인.

실제 화면의 체감 속도와 가독성은 사람이 플레이하며 확인해야 한다. 자동 검사는 전체 런 완주·시각 검수를 대신하지 않는다.
