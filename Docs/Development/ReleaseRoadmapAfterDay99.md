# 99일차 이후 남은 개발 일정 재배치안

작성일: 2026-10-10. 코드 기준: 98일차 커밋 4be7c4b와 이번 99일차 적용 내용.
기획 기준: Google Docs의 개발 방향 탭을 같은 날짜에 읽은 결과.

98일차는 임시 UI 제작, 99일차는 정예 전투 규칙·보상·해금 안내 연결로 완료했다. 기획서의 기존 98일차 보스 15종 기반과 99일차 경로·EV01~EV35 이벤트 작업은 이월 대상으로 관리한다. 일반적인 이벤트 처리 기반과 기존 보스 구현이 이 상세 콘텐츠의 완료를 의미하지 않는다.

기획서의 기존 100~120일차 일정에 이월 작업 두 구간을 앞에 배치하여 100~122일차, 총 23개 작업 일차로 제안한다. Google Docs를 이번 마무리 요청에서 수정하지 않았다. 각 일차는 작업 묶음이며 실제 달력의 하루나 출시 날짜를 보장하지 않는다.

## 병행 제작과 확인 조건

- 카드 Artwork·King 초상화·기물·보드 제품 자산은 103~117일차 동안 병행 제작 후 최종 검수. 98일차 임시 UI 프레임 45종과 구분.
- BGM·SFX·전투 연출도 103~117일차 동안 병행 제작·적용·검수. 저장소의 추적된 오디오 파일은 현재 확인되지 않음.
- 정예 25턴·2/4턴 증원, 적·보스·경제 임시값은 실제 전체 런 3회 이상 기록으로 조정. 자동 Seed 표본으로 대체하지 않음.
- 실제 Steam AppID·Depot·상점 자료와 심사 일정은 계정에서 별도 확인. 코드 기본 AppID는 현재 480.
- Steam 제출 준비는 118일차부터 진행하고, 122일차의 출시 판정은 심사 완료와 실제 RC 검증 결과를 전제로 관리.
- 보스·탐색·제품 자산의 분량이 커서 작업 일차를 여러 실제 작업일로 나눌 수 있음. 확정 출시일은 현재 산정하지 않음.
