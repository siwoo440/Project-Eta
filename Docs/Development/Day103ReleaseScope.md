# 103일차 출시 조작·설정 범위

기준: 102일차 커밋 `25be316`과 103일차 적용 코드. 이번 일차는 화면 전환과 입력 소유를 보완하고, 구현된 기능과 출시 지원 표시를 구분한다.

---
## 현재 검수 기준

Windows PC, 키보드·마우스, 한국어 중심 화면을 기본 검수 대상으로 둔다. 권장 검수 해상도는 1280×720·1920×1080과 1280×1024다. 실제 지원 기기·언어와 Steam 표시는 최종 출시 검수 후 확정하며, 이번 문서를 게임패드·다국어 완성 선언으로 사용하지 않는다.

| 분야 | 현재 구현 | 출시 전 남은 확인 |
|---|---|---|
| 전투·지도 | 마우스 선택·드래그, 손패 숫자키, 행동 완료 키 | 전체 런에서 실제 조작 완주 |
| 상점·이벤트 | 마우스, Tab/Shift+Tab·방향키 순환, Enter 확인, Backspace 취소/뒤로/나가기 | 모든 상품·대상 페이지의 플레이 검수 |
| 일시정지 | 저장된 Pause 키(기본 Esc), 하위 설정/조작법 → Pause → 게임 복귀 | 실제 창·포커스 환경의 반복 조작 |
| 걷기 | WASD·마우스 시선·의자 근처 F, 모달 중 이동 차단 | 실제 방 전체의 충돌·체감 속도 |
| 조작키 설정 | 행동 완료·Pause 저장 필드와 런타임 바인딩 서비스 | 설정의 조작 탭은 아직 비활성, 전체 재매핑 UI 후속 |
| 게임패드 | Input System의 UI 모듈 기반만 존재 | 보드·드래그·지도·걷기를 포함한 전 과정과 안내 미검증, 지원 완료로 표시하지 않음 |
| 언어 | 한국어 중심 문구와 일부 영어 상태명 | 언어 선택·번역 테이블·전체 번역·문구 확장 검수 후속 |
| 난이도 | 전투·보스 규칙·기본/강화형·난이도 집계 기반 | 쉬움/보통/어려움 사용자 선택 기능과 최종 밸런스 후속 |
| 화면 | 해상도·창 모드·UI 배율, 주요 고정 패널의 화면 안 맞춤 | 실제 전투 씬의 전체 HUD와 초광폭 등 추가 비율 검수 |
| 소리 | Master·BGM·SFX 볼륨 설정·미리보기·저장 기반 | 실제 제품 오디오 자산·체감·장치 검수 별도 |
| 접근성 | UI 배율·명시적 비용/불가 사유·일부 키보드 선택 | 별도 글자 배율·색각·재매핑·자막·전 과정 게임패드 등 후속 |

설정 저장의 640×360 하한은 값 보정 규칙이다. 그 크기에서 글자까지 읽기 편한 제품 지원을 보장하는 값은 아니다. 큰 UI 배율에서 고정 패널이 화면을 넘으면 패널을 균일하게 줄여 버튼 접근을 우선한다. 따라서 화면 공간을 넘어서까지 글자가 커지는 기능은 아니다.

---
## 화면과 입력 우선순위

1. 씬 전환·일시정지·디버그 등 상위 입력 소유를 먼저 확인한다.
2. 상점/이벤트·보상·튜토리얼·런 결과가 열리면 보드·지도·턴 완료·걷기·카메라 입력을 차단한다.
3. 상점/이벤트는 자신의 선택만, 보상은 자신의 카드 선택과 확정만 허용한다. 상위 모달이 열려 있으면 콜백도 실행하지 않는다.
4. 열기·닫기·확정에 사용한 같은 프레임의 입력을 뒤 화면에 전달하지 않는다. 숨기거나 재구성한 선택 페이지의 콜백은 무효다.
5. 일시정지에서 하위 화면을 닫으면 Pause로, Pause를 닫으면 원래 게임으로 복귀한다. 원래 시간·입력 활성·커서·유효한 UI 선택을 복원한다.

튜토리얼·런 결과 위에서 Pause를 열지 않는 기존 정책은 유지한다. Esc는 필수 이벤트를 건너뛰는 키가 아니다. 취소 버튼이 있는 대상 선택은 Backspace로 돌아갈 수 있으며, 취소 없는 필수 결과/선택은 정상 완료해야 한다.

이번 변경은 모달 간 입력 포커스와 선택 복원 범위다. OS 창 전환·장치 연결 해제·다중 모니터 전체 동작은 실제 빌드에서 추가 검수가 필요하다.

## 후속 일차와 구분

104일차는 기존 걷기 기반에 탐색 구역·조사 대상·상호작용 안내·테이블 복귀 흐름을 연결하는 방향이다. 정식 단서 콘텐츠와 영구 탐색 저장은 이후 작업으로 나눈다. 게임패드·다국어·별도 난이도를 이번 탐색 일차에 함께 완성한다고 약속하지 않는다.
