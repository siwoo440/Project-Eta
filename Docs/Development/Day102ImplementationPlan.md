# 102일차 경로·이벤트 구현 계획

> 실행 방식: superpowers:executing-plans로 이 채팅에서 순차 구현·검증. 사용자가 승인한 102일차 범위와 기획서의 로그라이크 이벤트 탭을 기준으로 적용.

**목표:** 5페이즈 경로의 전투 횟수를 목표 범위에 제한하고 EV01~EV35의 105개 선택지를 실제 화면·비용·카드·저장·손익 기록에 연결.

**구조:** 기존 경로·이벤트 API는 구버전 호환용으로 유지한다. 새 경로 규칙은 페이즈 생성의 실제 실행 경로에 연결한다. 이벤트는 Resources JSON 카탈로그, 독립 실행 서비스, 저장 세션·결과, 기존 보드 오버레이를 쓰는 화면 담당자로 분리한다.

**기술:** Unity 6000.3.21f1, C#, UGUI, JsonUtility, NUnit.
**사양:** 기존 101일차 개발일지의 102일차 방향과 Google Docs 로그라이크 이벤트 탭(EV01~EV35).

---
## 공통 제약

- Allman 스타일과 새 코드 각 줄의 짧은 한글 주석.
- 카드 직접 보상·교환은 런 시작에 해금된 1성, 동일 PieceId 정상·사망 합산 3개 제한.
- 왕 HP 비용으로 사망 금지, 회복은 최대치 제한, 카드 대상 확정 전 비용 부과 금지.
- 같은 런의 완료 EventId 재등장 금지, 노드별 한 번만 확정.
- 선택 단서는 후보 열람 이력만 기록하며 핵심 단서·진엔딩 필수 조건과 분리.
- 기존 저장 그래프와 선택한 이벤트 스냅샷 유지. 신규 규칙은 새로 만드는 경로에 적용.
- 현재 개발 단계에서는 커밋·푸시 없이 구현·검증 후 원본에 선택 적용.

## 중점 검토

취소 후 자원 보존, 같은 프레임 중복 클릭, 저장·복원 후 결과 재지급, 교환 시 자기 자신/잠긴 카드/보유 상한, 영구 열람 정보가 이미 있어도 기본 보상 유지.

실제 플레이 시간·승률은 자동 표본으로 확정하지 않는다. 이벤트 선택 단서 원문과 탐색 도감은 후속 일차다.
