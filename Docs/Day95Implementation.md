# 95일차 적용 안내

5성 8종의 능력을 플레이어 조작, AI, 피해 처리, 턴 처리와 저장 복원에 연결했다. 기준 커밋은 `6c2fc80`이며 HP·ATK, 이동 규칙, 81종 기물 등록과 70개 합성식은 유지했다.

---
## 개발 단계와 적용 결과

| 단계 | 적용 내용 |
|---|---|
| 1. 능력 데이터 연결 | 11개 능력 에셋 생성, 기존 5성 8종에 연결 |
| 2. 전투와 턴 처리 | 조건부 돌파 공격, 인접 보호, 황제 회복, 철벽군주 피해 분담 추가 |
| 3. 조작과 AI | 대현자 대상 선택 버튼, 환영장군 배치 형태 버튼, AI 독·회복·보호 후보 추가 |
| 4. 저장과 씬 연결 | 보호 소모·회복 발동·형태 복원, 빌드용 기물·상태 데이터 참조, 전투 씬마다 UI 설치 |
| 5. 회귀 검증 | 독으로 인한 승패, 왕 HP 동기화, 대형 기물 중복 정산·잔여 점유 수정 |

## 기물별 동작

| 기물 | 적용 동작 |
|---|---|
| 공성대장 | 기존 스크린 1개 포격과 원거리 처치 시 제자리 유지 규칙 보존, 능력 설명 연결 |
| 대성기사 | 인접 8칸 아군의 피해 2 감소, 수호자당 일반 턴 1회 |
| 기마장군 | 라이더 반복 도약 2회 이상 공격 시 피해 +2 |
| 환영장군 | 배치 턴에 시작 형태 선택, 이후 기존 이동 형태 순환 유지 |
| 황제 | 인접 아군 ATK +1 비중첩, 배치마다 부상 인접 아군 1개 HP +1 |
| 하늘원수 | 라이더 반복 도약 2회 이상 공격 시 피해 +2, 얼룩말 단일 도약 제외 |
| 대현자 | 공격 대신 거리 2 이내 회복 2·적 독 2중첩·아군 다음 피격 피해 1 감소 중 하나 선택 |
| 철벽군주 | 거리 2 이내 아군 피해 최대 2 분담, 자신 HP 1과 원래 대상 최소 피해 1 유지 |

대성기사 감소량·재사용 주기, 기마장군 추가 피해, 대현자 범위·보호 감소량은 기획서의 미정 항목에 적용한 **개발용 임시값**이다. 기존 임시 HP·ATK도 확정 밸런스로 간주하지 않는다.

황제의 최초 배치 회복은 배치를 마친 첫 플레이어 턴에 적용하며, 이후 주기 배치에서는 진입 시 적용한다. 같은 턴 이벤트를 다시 받아도 회복이나 보호가 재충전되지 않는다.

## 생성·수정·제거 요소

- 생성: `Scripts/Abilities/FiveStar*.cs` 4개, `RunContentCatalog.cs`, 11개 능력 에셋, Resources 참조 에셋 2개, 에디터 검증 메뉴, EditMode·PlayMode 테스트.
- 수정: 기존 5성 기물 8개, 전투·피해·턴·AI·보드 입력·저장 코드, 능력 패널 UI, 전투 씬 초기화.
- 제거: 기존 상태 정산 브리지의 반사 호출과 턴 종료 구독 교체 코드. 기존 컴포넌트와 정적 호환 API는 유지.
- 별도 씬·프리팹·Inspector 연결 작업 없음. 런타임에서 패널을 자동 생성.

## Unity에서 직접 확인할 조작

1. `F:\Project-Eta`를 열고 스크립트 컴파일 완료까지 대기.
2. `Project Eta > Day 95 > Validate Five Star Content` 실행. Console에서 5성 8종·능력 11개 연결 메시지 확인.
3. Boot 씬부터 게임 시작. 대현자 배치 후 일반 플레이어 턴에서 기물 선택 → 오른쪽 능력 패널의 회복·독·보호 선택 → 강조된 대상 클릭. 일반 행동 1회 소비 확인.
4. 배치 턴에 환영장군 선택 → 오른쪽 형태 버튼 선택. 위치를 이동하지 않고 형태만 변경되는지 확인.
5. 메뉴로 돌아왔다가 다시 전투 진입. 기물 선택 시 능력 패널이 다시 표시되는지 확인.

코드·데이터는 자동 적용 완료. 실제 화면에서 글자 크기·패널 겹침·클릭 감각을 확인하는 조작이며, 추가 수동 파일 수정 지시는 없다.
