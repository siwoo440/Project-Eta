# 96일차 구현 결과

일반 전투 5종과 정예 전투 3종의 편성 원형을 추가했다. 같은 지도 Seed와 노드에서는 같은 적 편성이 생성되며, 적은 보드 후방 3행의 서로 다른 칸에 배치된다.

---
## 적용 내용

- 일반 편성: 전열, 교란, 원거리, 방어, 혼합
- 정예 편성: 선봉, 요새, 사냥
- 일반·특수 기물은 1~2성만 허용하고 적 전용 몬스터는 등급과 관계없이 허용
- 정예 전투는 일반 전투보다 적 수와 위협도가 높도록 구성
- 전투 시작 시 편성 ID, 적 목록, 적 수, 위협도, 왕 HP 기록
- 전투 종료 시 승패, 종료 턴, 왕 HP 기록
- 일반 AI와 보스가 왕을 처치한 경로도 런 실패와 측정 완료 처리
- F1 상태 페이지에 최근 편성 원형, 위협도, 승패, 종료 턴 표시
- JSON·CSV 내보내기에 편성·전투 결과 열 추가

---
## 자동 검증

- 96일차 EditMode 테스트 15개 통과
- 1~5페이즈 일반·정예 5,000개 편성 표본 검증
- 모든 원형 사용, 중복 칸 없음, 후방 3행 배치 확인
- 5페이즈 평균 위협도가 1페이즈보다 높음을 확인

표본 결과는 [Day96EnemyEncounterSampling.md](Validation/Day96EnemyEncounterSampling.md)에서 확인한다.

---
## 실제 플레이 확인

1. Boot 씬에서 새 런 시작
2. 일반·정예 노드 전투 진입
3. F1 상태 페이지에서 최근 편성·위협도 확인
4. 승리와 패배 후 최근 결과·종료 턴 확인
5. JSON·CSV 내보내기 후 Encounter와 BattleResult 행 확인

자동 표본은 적 구성 난이도만 비교한다. 실제 승률, 평균 종료 턴, 왕 HP 손실은 3런 이상 플레이 기록을 수집한 뒤 조정해야 한다.
