# 프로젝트 η — 핵심 개발 규칙 체크리스트

> 출처: 프로젝트 η 게임 기획서 (기획 탭) — 2026-09-03 기준 발췌·정리.
> 목적: 코드 구현 중 기획서를 매번 다시 찾지 않도록 프로그래머 관점에서 핵심 수치·규칙만 정리.
> 새 규칙이 확정되거나 변경되면 이 문서를 갱신할 것 — 기획서가 원본, 이 문서는 요약본.

## [확정] 규칙

- 보드: 10×10 격자 고정. 모든 이동·공격·배치·점유 판정은 칸 단위 좌표 기준.
- 배치 영역: 보드를 진영별 10×5로 절반 분할. 각 진영은 자기 영역의 빈 칸에 자유 배치.
- 한 칸에는 기본적으로 기물 1개만 존재. 아군·적군 모두 다른 기물을 통과 불가(룩/비숍/퀸형은 경로 차단, 나이트형은 도약으로 무시).
- 2×2 이상 대형 점유 기물은 초기 출시에서 몬스터·보스 전용으로 제한.
- 이동과 공격은 하나의 칸 선택 행동으로 통합 처리.
  - 빈 칸 선택 → 이동.
  - 적이 있는 칸 선택 → 공격.
  - 비치명 공격(대상 생존) → 공격자는 원위치로 복귀.
  - 치명 공격(근접 직접 공격으로 처치) → 공격자가 대상 칸을 점유.
  - 지속 피해·환경 피해로 사망한 경우 공격자 칸 점유 없음(근접 직접 공격에만 점유 적용).
- 킹(플레이어): 초기 HP 3, ATK 보유. 8방향 1칸 이동. 체크/체크메이트 없음 — HP 0이면 즉시 런 패배.
  - 킹이 적을 처치하면 대상 칸으로 이동(일반 근접 기물과 동일 규칙, 별도 치명 판정 없음).
  - 위험한 칸(다음 적 턴에 피격 가능) 이동 허용, 옅은 빨간색으로 표시만.
  - 초기 출시 3종 킹(전투·방어형/카드형/합성형), 공통 HP 3, ATK·패시브·액티브·시작덱 상이.
  - 킹 성장: 부활·자동 보호 없음. 액티브 스킬은 마나 대신 턴 쿨다운.
- 승리/패배: 일반 라운드는 적 전원 처치 시 승리. 킹 HP 0 또는 라운드 턴 제한 초과 시 해당 런 패배(처음부터 재시작).
- 카드/손패: 손패 최대 10장. 일반 턴 드로우 1장, 배치 턴 드로우 3장. 손패 10장 상태에서는 드로우 스킵(덱 맨 위 유지). 카드에 배치·마나 코스트 없음.
- 배치 턴(20일차 갱신, 기획서 원문에서 변경 확정): 시작 배치·5턴 주기 배치 턴 모두 손패가 허용하는 만큼 자유롭게 여러 장 배치 가능(장수 제한 없음). 기획서 원문의 "배치 턴당 기본 1개 제한"은 폐기하고 이 자유 배치 방식을 확정 규칙으로 채택.
- 죽은 카드 덱: 보드 기물 사망 시 카드로 전환되어 해당 라운드 동안 봉인(재드로우·재배치 불가). 라운드 종료 시 보유 카드 풀로 복귀 — 런 전체에서 영구 소멸 아님.
- 합성: 배치 턴에만 손패 카드끼리 수행. 기본은 서로 다른 카드 2장 소모 → 결과 카드 1장, 같은 배치 턴에 바로 배치 가능. 확정적 처리(성공 확률 없음), 별도 자원 소비 없음. 기본은 한 번에 한 등급만 상승(2단계 이상 스킵 없음).
- 기물 등급: 1~5성. 5성은 기본적으로 최종 합성으로만 획득, 동일 최상위 기물 1개 제한이 기본안.
- 합성 관계는 페어리 체스 이동 규칙 결합을 기본 참고로 사용(예: Bishop+Knight→Archbishop, Rook+Knight→Chancellor, Queen+Knight→Amazon).
- 최종적으로 로그라이크/로그라이트 런 구조 사용. 런 패배 시 처음부터 재시작.
- 폰 이동(7일차 확정, 1차 구현): 매 턴 전방으로 최대 2칸까지 이동 가능(첫 이동 제한 없음). 1칸이 막히면 2칸째로 진행 불가.
- 폰 공격(7일차 확정, 1차 구현): 전방 1칸 + 대각선 앞 좌우 1칸까지 공격 가능. 대각선 칸은 적이 있을 때만 공격 대상이며 이동(빈 칸 전진)으로는 사용 불가.

## 사용 원칙

- 코드에 매직 넘버를 박아 넣을 때는 이 문서의 [확정] 값만 하드코딩 후보로 삼는다.
- [테스트 값]과 [미정] 값은 반드시 `ScriptableObject` 등 데이터 자산으로 빼서 코드 수정 없이 조정 가능하게 한다.
- 기획서 원문과 이 체크리스트가 어긋나면 기획서(구글 문서 "기획" 탭)를 우선한다.
