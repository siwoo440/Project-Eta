# 103일차 : 화면 입력 충돌 차단과 UI 복원 개선

- 개발·마무리 기록일: 2026-10-21
- 기준 커밋: `25be316` — 102일차 : 경로 분기와 기획 이벤트 35종 구현
- 적용 프로젝트: `F:\Project-Eta`

---
## 개발 결과

전투·지도·걷기·이벤트·보상·설정을 오갈 때 입력이 뒤 화면으로 전달되지 않도록 보완했다. 일시정지 전의 시간·커서·입력·능력 버튼·합성 모드 복원을 연결하고, 주요 패널이 큰 UI 배율에서도 화면 안에 들어오도록 수정했다.

---
## 작업 내용

- 모달·씬 전환·시스템 키·걷기를 함께 확인하는 공통 입력 판정 추가
- 보드·지도·카드 소환·행동 완료의 뒤 화면 입력 관통 차단 추가
- 일시정지·F1을 걷기·보드보다 먼저 처리하도록 실행 순서 수정
- 열기·닫기·선택에 사용한 같은 프레임의 입력 재사용 차단 추가
- Pause 비활성화 시 하위 화면·시간·입력·커서·이전 포커스 복원 수정
- 상점·이벤트의 현재 페이지·표시 상태·선택 가능 여부 검사 추가
- Tab·Shift+Tab·방향키 선택과 Enter 확정·Backspace 뒤로가기 추가
- 기본 Input Module Submit과 선택 화면 Enter의 중복 실행 차단 추가
- 일시정지·디버그 아래 카드 보상 선택·확정 차단 추가
- 모달 중 능력 버튼 재생성과 합성 모드 자동 종료 문제 수정
- Shift+방향키의 방향 의미를 유지하도록 선택 이동 수정
- 설정·Pause·조작법·메인 메뉴의 화면 범위 맞춤 추가
- 최대 UI 배율의 첫 표시 프레임과 설정 취소 배율 복원 수정
- UI 배율 135%가 100%로 표시되던 퍼센트 문구 수정
- 실제 UI·입력·생명주기 회귀 검사 14개 추가
- 구현·출시 지원 범위·검증 문서 추가

씬·Prefab·원본 이미지·저장 포맷 변경과 파일 삭제는 없다. Inspector 수동 연결 없이 런타임에서 자동 적용한다.

| 검사 | 결과 |
|---|---|
| 전체 EditMode | 995개 통과·실패 0개 |
| 전체 PlayMode | 40개 통과·실패 0개 |
| Windows 64비트 개발 빌드 | 성공·실행 파일 생성 확인 |
| 실제 UI 렌더 | 최대 배율 135%의 7개 화면 영역 검사 통과 |
| 코드 리뷰 지적 | 능력 버튼 포커스 문제와 방향키 항목 재현·수정 |
| 연관 회귀 | 합성 모드 해제 문제 재현·수정 |
| 원본 소스 대조 | 적용 24개·그 외 추적 C# 491개 일치 |

실제 키·버튼·UI·카드·시간·커서로 검사했다. 독립 UI 렌더와 자동 검사는 사람이 실제 전체 런을 완주한 결과가 아니다.

---
## 조작·적용 확인

1. Unity 재생을 중지하고 컴파일 완료를 기다린다.
2. 전투·지도에서 Esc+W를 함께 눌러 Pause가 먼저 열리는지 확인한다.
3. 걷기 중 Pause를 열고 닫은 뒤 이동·커서·좌석 복귀 HUD를 확인한다.
4. 상점·이벤트에서 Tab/방향키·Enter로 선택하고, 취소 버튼이 있는 페이지에서 Backspace로 복귀한다.
5. 보상·이벤트 위 Pause에서 뒤쪽 선택이 실행되지 않는지 확인한다.
6. 능력 버튼 선택·합성 모드를 유지한 채 Pause와 설정을 반복해서 오간다.
7. UI 배율을 최대로 높여 메뉴와 하단 버튼을 확인하고 취소 시 원래 배율로 돌아오는지 확인한다.

---
## 현재 범위

- 기존 화면 구조와 필수 이벤트 완료 규칙 유지, Esc로 필수 선택 건너뛰기 없음.
- 화면 맞춤은 설정·Pause·조작법·메인 메뉴의 주요 고정 패널 대상.
- 별도 언어 선택·완전한 게임패드 조작·사용자 난이도 선택·접근성 전체 구현은 후속.
- 실제 전체 런·창 포커스·장치·초광폭과 최종 가독성은 수동 검수 대상.
- 큰 UI 배율이 화면을 넘으면 버튼 접근을 위해 패널을 균일하게 축소.

## 104일차 개발 방향

쉽게 말하면 ‘방을 걸어 다닐 수 있는 상태’를 ‘방 안에서 물건을 살펴보고 진행할 수 있는 탐색’으로 확장하는 작업이다.

1. 이동 가능한 구역·테이블·의자·문 주변의 충돌과 이동 동선 정리.
2. 조사 대상 데이터와 바라보기·거리 조건, 상호작용 안내 연결.
3. 조사창 열기·닫기와 이동/시선 입력 차단·복원 연결.
4. 의자 F 복귀와 조사 상호작용의 우선순위 정리.
5. 기본 조사 대상부터 진행 불가·반복 입력·복귀 흐름 검사.

정식 핵심 8단서·선택 단서 전체 콘텐츠·구역 개방 선행 조건·영구 탐색 저장은 이후 단계로 나눈다. 이번 일차의 모달 보호를 조사 화면에도 재사용한다.
