# 18일차 개발 일지 — 이미지 손패 UI 및 드래그 앤 드롭 소환

**날짜**: 2026-09-03  
**목표**: 기존 텍스트 기반 손패와 숫자키 중심 소환 흐름을 실제 카드 이미지 UI와 드래그 앤 드롭 조작으로 확장하고, 드래그 중 3D 기물 고스트를 이용해 소환 위치를 직관적으로 확인할 수 있도록 한다.

## 오늘 한 일

### 1. 실제 카드 형태의 손패 UI 추가
- 화면 하단 중앙에 실제 손패를 카드 형태로 표시하는 `HandUI` 추가.
- 각 손패 카드는 `CardView`에서 런타임 UI로 생성.
- 판타지 카드 형태로 다음 정보를 표시:
  - 상단 원형/타원형 카드 일러스트 영역.
  - 중앙 기물 이름 배너.
  - 하단 설명 영역.
  - 좌상단 등급.
  - 좌하단 ATK.
  - 우하단 HP.
  - 우상단 숫자키 보조 입력.
- 실제 Artwork가 연결되지 않은 카드도 기물 약칭을 표시해 시스템 테스트 가능.

### 2. PieceDefinition에 카드 Artwork 연결 추가
- 각 기물 데이터에 카드용 `Sprite`를 연결할 수 있도록 `CardArtwork` 필드 추가.
- King / Pawn / Knight / Bishop / Rook / Queen 카드마다 서로 다른 이미지 사용 가능.
- Artwork가 없는 경우 임시 텍스트 초상화로 대체.

### 3. 손패와 실제 HandState 동기화
- `BattleController`가 런타임에 `HandUI`를 준비하고 실제 `BoardInputController`에 연결.
- 카드 드로우와 소환으로 손패가 바뀔 때 `HandChanged` 이벤트를 통해 UI 갱신.
- 실제 `HandState` 순서와 카드 UI 순서를 동일하게 유지.

### 4. 카드 드래그 앤 드롭 소환
- 카드에 좌클릭 드래그 입력 추가.
- 카드 드래그 중 화면 좌표를 3D 보드 Raycast로 변환.
- 좌클릭을 놓는 `OnEndDrag` 시점에서만 실제 소환 판정 수행.
- 유효한 아군 영역의 빈 칸에 Drop하면 실제 기물 소환.
- 잘못된 위치에 놓으면:
  - 카드를 소비하지 않음.
  - 실제 보드 상태를 변경하지 않음.
  - 손패 카드가 원래 위치로 복귀.

### 5. 기존 숫자키 입력 유지
- 카드 UI가 안정화되는 동안 기존 숫자키 `1~0` 손패 슬롯 선택도 보조 입력으로 유지.
- 주 조작은 마우스 드래그 앤 드롭을 기준으로 사용.

### 6. 시작 킹 필수 규칙을 카드 UI에 연결
- 초기 배치 턴에는 킹 카드만 먼저 사용할 수 있도록 나머지 카드를 잠금 표시.
- 킹을 실제 보드에 배치한 이후 다른 카드도 자유롭게 배치 가능.
- 킹이 배치되지 않으면 시작 배치 턴 종료 불가.

### 7. 일반 플레이어 턴 카드 소환 연결
- 일반 `PlayerTurn`에서도 손패 카드를 드래그하여 아군 10×5 영역에 소환 가능.
- 카드 소환을 이동/공격과 동일한 한 턴 행동 1회로 처리.
- 일반 플레이어 턴에서 소환 성공 시 즉시 `EnemyTurn`으로 진행.
- 배치 턴에서는 여러 장을 자유롭게 배치하며 자동 턴 종료하지 않음.

### 8. 드래그 중 손패 숨김
- 카드를 보드 방향으로 위로 끌어올리면 손패 전체가 화면 아래로 내려가도록 변경.
- 손패 UI가 보드와 소환 위치를 가리는 문제를 줄임.
- Drop 성공 또는 실패로 드래그가 끝나면 손패가 다시 원래 위치로 복귀.

### 9. 3D 기물 고스트 프리뷰 추가
- 드래그 중 커서가 가리키는 보드 셀에 실제 기물 형태의 고스트 프리뷰 표시.
- 기존 `PieceView` 모델 형태를 재사용해 King / Pawn / Knight / Bishop / Rook / Queen의 실제 윤곽 확인 가능.
- 고스트는 실제 BoardState에 등록되지 않는 미리보기 전용 객체.
- 유효한 소환 위치와 무효 위치를 서로 다른 반투명 색으로 표시.
- 고스트 Collider를 비활성화해 보드 Raycast를 방해하지 않도록 처리.

### 10. 드래그 중 카드 UI 숨김
- 초기 구현에서는 카드 이미지와 3D 고스트가 동시에 표시되어 소환 위치가 복잡하게 보였음.
- 최종 수정에서는 드래그가 시작되면 현재 드래그 카드 UI를 완전히 숨김.
- 드래그 중에는 3D 기물 고스트만 표시.
- 좌클릭 Release 후:
  - 소환 성공 → 사용한 카드 제거.
  - 소환 실패 → 카드 UI 다시 표시 및 손패 복귀.

### 11. CanvasGroup MissingComponentException 수정
발생 오류:

```text
MissingComponentException:
There is no 'CanvasGroup' attached to the "CardView_1_King" game object
```

원인:
- `CardView`가 `RectTransform` 존재 여부만 보고 시각 트리가 이미 초기화된 것으로 판단할 수 있었음.
- 일부 카드 오브젝트가 `RectTransform`은 있지만 `CanvasGroup`이 없는 부분 초기화 상태가 될 수 있었음.
- `OnBeginDrag` / `OnEndDrag`에서 `_canvasGroup`을 바로 사용해 예외 발생.

수정:
- `CanvasGroup`을 카드 초기화 시 반드시 확보.
- 드래그 시작·종료 시에도 `CanvasGroup` 존재 여부를 방어적으로 확인하고 필요 시 자동 추가.
- 부분 초기화된 CardView도 드래그 입력을 안전하게 처리하도록 보완.

### 12. 드래그 중 손패 Refresh 안정화
- 카드 소환 성공과 동시에 손패 UI가 재구성되면 현재 `OnEndDrag`가 실행 중인 CardView가 제거될 가능성이 있었음.
- 드래그 콜백 정리가 끝난 뒤 손패 UI를 갱신하는 흐름으로 조정.
- 소환 성공/실패 모두 고스트·손패 위치·카드 표시 상태를 일관되게 정리.

## 최종 조작 흐름

### 시작 배치

```text
전투 시작
↓
하단 이미지 손패 표시
↓
King 카드 좌클릭 Drag
↓
카드 UI 숨김
↓
손패가 화면 아래로 이동
↓
보드에 King 3D 고스트 표시
↓
유효한 아군 칸에서 좌클릭 Release
↓
King 실제 소환
↓
다른 카드도 자유 배치 가능
↓
Space
↓
1턴 시작
```

### 일반 플레이어 턴

```text
카드 Drag
↓
카드 UI 숨김
↓
3D 기물 고스트로 위치 확인
↓
좌클릭 Release
↓
유효한 위치면 실제 소환
↓
손패에서 카드 제거
↓
즉시 EnemyTurn
```

```text
카드 Drag
↓
보드 밖 / 적 영역 / 점유 칸
↓
좌클릭 Release
↓
소환 실패
↓
고스트 제거
↓
손패 복귀
↓
카드 다시 표시
```
