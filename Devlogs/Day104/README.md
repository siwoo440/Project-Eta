# 104일차 : 방 조사 상호작용과 탐색 UI 추가

- 개발·마무리 기록일: 2026-10-22
- 기준 커밋: `ecff67e` — 103일차 : 화면 입력 충돌 차단과 UI 복원 개선
- 적용 프로젝트: `F:\Project-Eta`

---
## 개발 결과

방을 걷다가 가까운 물건을 바라보고 F로 조사할 수 있도록 연결했다. 기록대·기물 진열대·벽의 금속 장식·잠긴 출입문을 자동 배치하고, 조사창과 기존 이동·의자 복귀·일시정지 화면이 입력을 함께 처리하지 않도록 보완했다.

---
## 작업 내용

- 조사 대상 4종의 고정 ID·설명·위치·방향 데이터 추가
- 기존 방 가장자리의 임시 모델과 걷기 충돌체 자동 배치 추가
- 실제 거리·바라보기·벽과 테이블 가림을 사용하는 조사 판정 추가
- 조사 가능한 대상의 밝은 금빛 테두리와 중앙 조준점 추가
- 하단 구역·대상 이름·확인 이력 안내 추가
- 하단 안내 글자가 프레임에 닿지 않도록 높이와 여백 수정
- 기존 패널·버튼 이미지를 재사용하는 한글 조사창 추가
- F 조사와 F·Enter·Backspace·버튼 닫기 추가
- 조사 중 이동·시선 차단과 닫기 후 커서·걷기 복원 추가
- 의자 근처 F 앉기 우선순위와 같은 프레임 중복 입력 차단 추가
- 조사 위 Pause 유지와 필수 진행 화면의 좌석 복귀 처리 수정
- 외부 시점 고정 중 필수 화면 복귀가 누락되던 순서 수정
- 담당자·UI 비활성화와 이동기 단독 파괴의 모달·모델 정리 수정
- 현재 방에서 같은 물건을 다시 확인해도 중복되지 않는 확인 이력 추가
- 실제 입력·물리·UI·수명 회귀 검사 17개 추가
- 구현·계획·검증 문서와 개발일지 추가

기존 씬·Prefab·원본 이미지·저장 포맷 변경과 파일 삭제는 없다. Inspector 수동 연결 없이 기존 좌석 카메라에서 자동 적용한다.

자동 검사는 실제 InputSystem·CharacterController·Collider·UGUI를 사용했다. 독립 에디터 렌더와 자동 검사는 사람이 실제 전체 런을 완주하거나 방을 연속 탐색한 결과가 아니다.

## 조작·적용 확인

1. Unity 재생을 중지하고 컴파일 완료를 기다린다.
2. Battle에서 WASD로 일어나 서쪽 기록대나 동쪽 기물 진열대로 이동한다.
3. 가까운 물건을 바라보고 금빛 테두리와 하단 안내가 나오면 F로 조사한다.
4. F·Enter·Backspace·닫기 버튼으로 닫은 뒤 이동과 시선 복원을 확인한다.
5. 조사창에서 Esc로 Pause를 열고 닫아 같은 조사창이 유지되는지 확인한다.
6. 남쪽 잠긴 문과 북쪽 벽 장식을 조사하고 의자 근처에서 F로 앉는다.

---
## 현재 범위

- 네 모델과 조사 설명은 기초 흐름 확인용 임시 콘텐츠다.
- 확인 이력은 현재 방 인스턴스에서만 유지하며 정식 단서·도감·영구 저장과 구분한다.
- 출입문은 잠겨 있으며 구역 개방과 후속 방 진입은 아직 없다.
- 조사창 자체는 전투 시간을 멈추지 않으며 이동·시선 입력만 차단한다.
- 고정 F 조사·앉기보다 상위 화면 입력이 우선한다.

## 105일차 개발 방향

쉽게 말하면 물건의 설명을 읽는 단계에서, 발견한 단서를 목록에 모아 다시 확인하는 단계로 확장한다.

1. 핵심·선택 단서를 구분하는 고정 ID·제목·내용·발견 조건 데이터 구조 정리.
2. 기존 네 조사 대상에 첫 단서 획득 경로를 연결하고 일반 조사 확인과 단서 발견을 구분.
3. 발견한 단서를 제목·내용으로 다시 읽는 단서 목록 화면 추가.
4. 같은 단서의 중복 획득·반복 알림 방지와 선행 조건 판정 추가.
5. 조사·단서 목록·Pause·의자 복귀 사이 입력과 진행 불가 회귀 검사.

기존 이벤트 정보 열람 ID는 정식 단서 원문이 아니므로 대응 관계를 명시한다. 핵심 8개·선택 약 16개의 전체 콘텐츠는 105~106일차 범위로 나누고, 영구 저장·복원은 107일차에서 연결하는 방향이다. 정식 단서 원문·세부 개방 조건은 기획 근거를 확인한 뒤 확정한다.
