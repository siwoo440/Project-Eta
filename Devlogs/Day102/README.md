# 102일차 : 경로 분기와 기획 이벤트 35종 구현

- 개발·마무리 기록일: 2026-10-21
- 기준 커밋: `177eaaa` — 101일차 : 보스 선택·저장 기반과 이동 UI 개선
- 적용 프로젝트: `F:\Project-Eta`

---
## 개발 결과

새 런의 지도에서 전투·상점·보상·이벤트를 선택하는 2~3분기 경로를 구성했다. 기획 이벤트 EV01~EV35의 A·B·C, 총 105개 선택지를 실제 비용·카드·HP 변화·저장·결과 화면에 연결했다.

---
## 작업 내용

- 신규 경로의 깊이별 노드 종류·가중치·연속 제한·보스 배치 규칙 추가
- 페이즈 시작점 자동 완료를 포함해 신규 런 전체 전투 21~24회 구성으로 수정
- Seed 기반 경로 생성과 기존 저장 그래프 유지 처리 수정
- 공통 10종·페이즈 전용 각 5종의 이벤트 35종·105개 선택지 데이터 추가
- 보유 자원·왕 생존·최대 HP·대상 카드·해금·동일 기물 수량 검사 추가
- HP·ATK 개별 강화와 1성 획득·제거·다른 기물 교환 효과 추가
- 공개·발견 합성 레시피의 1성 재료를 사용하는 연결 보상 추가
- 이벤트 선택 전 비용·효과·선택 불가 이유의 상시 표시 추가
- 대상 카드 두 장과 이전·다음·취소 버튼을 별도 행으로 배치하도록 수정
- 상세 카드 재사용 시 진행 버튼 제목 위치 초기화와 탐색 글자 크기 수정
- 선택 후 실제 Gold·왕 HP·카드 변화 표시와 손익 기록 추가
- 최초 이벤트 정의·Seed·선택 결과의 안전 체크포인트 저장·복원 추가
- 중복 입력·이어하기 재지급 차단과 저장 실패 재시도 추가
- 같은 런의 완료 이벤트 재등장 제외와 후보 소진 시 무보상 통과 추가
- 선택 정보 후보의 영구 열람 이력과 중복 열람 시 기본 보상 유지 추가
- 구형 7종 이벤트 화면을 신규 실행 흐름으로 수정
- 경로·105선택지·저장·실제 UI 회귀 검사와 구현·이벤트·검증 문서 추가

파일 삭제와 씬·Prefab·원본 이미지 변경은 없다. 별도 Inspector 수동 연결도 없다. 구형 정적 이벤트 API는 호환용으로 유지한다.

Unity 6000.3.21f1 검증 복사본에서 마무리 전체 테스트를 다시 실행했다. Windows 빌드는 최종 구현 완료 시 성공한 동일 소스 결과다. 마무리에는 소스 해시를 다시 대조했으며 문서 추가 후 실행 파일을 다시 빌드하지 않았다.

실제 UI 렌더는 독립 검증 씬의 Canvas를 정면에서 확인한 결과다. 사람이 실제 게임의 전체 런을 완주한 결과는 아니다.

## 적용 범위와 남은 사항

- 21~24전투는 신규 런의 보스 포함 구조적 횟수이며 플레이 시간·승률 측정값이 아니다.
- 정상적인 기존 저장 경로는 유지한다. 신규 규칙은 새 경로 생성에 적용한다.
- 구형 이벤트 저장에 신규 스냅샷이 없으면 현재 노드에서 신규 풀의 이벤트를 최초 고정한다.
- 경로·이벤트 추첨 가중치와 기획서의 비용·효과 수치는 임시값이다.
- 카드 보상·교환은 런 시작 시 해금된 1성, 정상·사망 합산 동일 PieceId 최대 3개 규칙을 사용한다.
- 선택 단서는 후보 열람 ID·안내까지 구현했다. 정식 단서 원문·핵심 8단서·도감·진엔딩 조건은 후속 작업이다.
- 실제 보드 카메라에서의 가독성과 전체 런 난이도·소요 시간은 수동 검수가 남았다.

## Unity 확인 순서

1. 재생을 중지하고 에셋 가져오기·컴파일 완료를 기다린다.
2. 새 런의 첫 전투 후 분기 지도와 상점·이벤트·보상 노출을 확인한다.
3. 이벤트의 비용·효과·비활성 사유를 읽고 대상 화면에서 취소해 자원이 유지되는지 확인한다.
4. 카드가 많은 상태에서 이전·다음으로 마지막 대상까지 이동한다.
5. 선택 후 실제 손익을 확인하고 이어하기에서 같은 결과가 유지되는지 확인한다.
6. ‘다음 경로’를 눌러 지도로 복귀한다.

## 103일차 개발 방향

쉽게 말하면 전투·지도·이벤트·걷기·설정을 오가더라도 화면과 조작이 서로 방해하지 않도록 정리하는 작업이다. 콘텐츠를 확장한 뒤 실제 플레이 흐름을 안정화한다.

추가 100일차의 이동 작업으로 순연된 기존 일정의 ‘전체 화면 흐름·HUD·출시 조작 범위 정리’를 103일차로 이어간다. 기존 ReleaseRoadmapAfterDay99.md는 작성 당시의 재배치안이며 이후 추가 일차를 반영한 확정 일정표가 아니다.

1. 타이틀 → 새 게임/이어하기 → 지도 → 전투 → 보상/상점/이벤트 → 결과의 화면 전환·뒤로가기 규칙 정리.
2. 걷기·좌석 복귀·일시정지·F1·선택 화면이 겹칠 때 HUD 표시·클릭·커서·입력 우선순위 정리.
3. 현재 행동 완료·일시정지 중심인 키 설정과 선택 화면의 키보드 이동·확인·취소 동작 점검·보완.
4. 해상도·UI 배율·긴 문구의 HUD 정렬과 설정 적용·취소·복원 검사.
5. 지원 언어·게임패드·난이도·접근성의 현재 구현과 출시 지원 범위를 구분해 문서화. 모든 지원을 이번 일차에 완료한다는 의미는 아니다.

완료 기준은 주요 화면을 반복 전환해도 입력이 중복되거나 클릭이 뒤 화면으로 새지 않고, 걷기/설정 복귀 시 화면·커서·설정 상태가 맞게 복원되는 것이다. 실제 전환 흐름 검사를 추가한다.
