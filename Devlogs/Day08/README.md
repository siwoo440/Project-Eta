# 8일차 개발 일지 — 1단계 통합 및 정리

**날짜**: 2026-09-03
**목표**: 1단계(1~8일차) 마무리. 지금까지 쌓인 구조를 점검·정리하고, 2단계(보드·턴·이동·HP 전투 핵심 구현)를 바로 시작할 수 있는 상태를 만든다.

## 오늘 한 일

### 1. 보드 구조 정리 — 타일 100개 → 하나의 체스판 메시
- 기존에는 `BoardView`가 `Quad` Primitive 100개를 개별 GameObject로 생성해 붙여놓은 방식이라, 화면에서 "여러 작은 칸이 붙어있는" 것처럼 보이는 문제가 있었음.
- `BoardView`를 정점 공유 없는 10×10 칸을 하나의 메시로 합치는 방식으로 재구성. 렌더러·콜라이더가 각각 1개(`MeshFilter`/`MeshRenderer`/`MeshCollider`)뿐인 진짜 "하나의 판"이 됨.
- 칸별 강조 표시(선택 시 파랑/빨강)는 서브메시 사이에서 삼각형 인덱스를 옮기는 방식으로 대체.
- 클릭 판정은 보드 전체의 `MeshCollider` + 히트 지점을 칸 좌표로 역산하는 `TryGetCellFromWorldPoint`로 대체.
- 더 이상 쓰이지 않는 `TileView.cs`(불필요한 임시 코드) 제거, `BoardInputController`를 새 API에 맞게 정리.

### 2. 보드 시각 마감 — 흑백 체스판 패턴 + 격자선
- 좌표 합의 홀짝으로 밝은/어두운 칸을 나눠 전통 체스판처럼 보이도록 서브메시를 4개(밝은 칸/어두운 칸/설치가능 강조/설치불가 강조)로 확장.
- 런타임에 생성한 격자선 텍스처를 모든 서브메시 머티리얼에 공통 적용해 칸 경계가 항상 뚜렷하게 보이도록 함.
- 칸 선택을 해제하면 원래 있던 밝은/어두운 색으로 정확히 복귀하도록 `HighlightCell`/`ClearHighlight` 로직 수정.

### 3. 사용자 확인 사항
- Battle 씬 Play → 보드가 하나로 이어진 흑백 체스판으로 보이고 격자선이 뚜렷한 것을 확인.
- `1`/`2` 키로 킹/폰 카드를 선택하고 아군 영역(파란 강조) 클릭 시 그 자리에 기물이 정상 소환되는 것을 확인.

## 오늘 하지 않은 것

- `BoardView`/`RunState`가 각자 별도의 `BoardState`를 갖는 구조(화면 보드와 저장용 보드가 분리된 상태)를 하나로 합치는 리팩터링은 이번엔 진행하지 않음 — 2단계에서 턴·전투 시스템을 실제로 붙이는 시점에 `BattleController`(가칭)로 통합 예정.
- 이동 계산 결과(`MovementResolver`)를 실제 클릭 이동에 연결하는 것 — 2단계(16~30일차) 예정.
