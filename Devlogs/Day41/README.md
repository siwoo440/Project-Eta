# 41일차 : 전투 공간·테이블 시점 구축

## 개발 목표

기존 10×10 보드를 거대한 폐쇄형 방 중앙의 테이블 위에 배치하고, 플레이어가 상대와 마주 앉아 대국하는 형태의 전투 공간과 카메라 시점을 구축한다.

## 주요 개발 내용

### 거대 전투실 환경

- Battle 씬 진입 시 전투 공간을 런타임에서 자동 생성하도록 구성
- 대형 바닥·벽·천장 패널과 구조 보, 코너 기둥을 이용한 폐쇄형 방 제작
- 저채도 회색 패널과 어두운 구조물을 이용해 거대한 실내 공간의 스케일감을 표현
- 환경광·안개·테이블 중심 조명을 적용해 보드 가독성과 공간 깊이감을 확보

### 테이블·좌석 구성

- 기존 10×10 보드를 방 중앙의 대형 테이블 위에 배치
- 보드 외곽 프레임과 테이블 구조물을 추가
- 플레이어 좌석과 상대 좌석을 서로 마주 보는 방향으로 배치
- 상대 좌석에 익명 실루엣 형태의 인물 모델을 Primitive 조합으로 구성
- 환경 오브젝트가 기존 보드 클릭 판정을 방해하지 않도록 충돌 요소를 최소화

### 3단계 카메라 뷰

전투 카메라를 세 가지 상태로 구분한다.

1. 맨 위 뷰
   - 전체 보드를 높은 위치에서 확인하는 시점
   - 기존 상단 카메라 역할을 담당

2. 기본 뷰
   - 플레이어가 테이블 앞에서 보드를 내려다보는 기본 전투 시점
   - 게임 시작 시 기본 카메라 상태

3. 상대 시점
   - 플레이어가 의자에 앉아 상대를 바라보는 시점
   - 마우스 우클릭 상태에서 마우스를 움직여 고개를 상하좌우로 회전 가능
   - 좌우 회전은 기준 방향에서 최대 180도 범위로 제한
   - 상하 회전은 카메라 반전을 방지하는 범위로 제한

### 카메라 조작

- `W` : 기본 뷰와 맨 위 뷰 전환
- 상대 시점에서 `W` : 기본 뷰로 복귀
- `S` : 상대 시점으로 전환
- 상대 시점에서 `우클릭 + 마우스 이동` : 자유 시야 회전
- 마우스 휠 : 제한적인 카메라 줌

### Top 뷰 가림 보정

- 맨 위 뷰에서 천장 중앙 조명 구조가 카메라 앞을 가리는 문제 확인
- 천장 조명 구조를 별도 가림 요소 그룹으로 분리
- 맨 위 뷰 진입 시 해당 구조를 자동 비활성화
- 기본 뷰·상대 시점 복귀 시 다시 활성화

### 테스트

- 전투실 크기와 주요 배치 좌표를 검증하는 EditMode 테스트 추가
- Battle 씬 전용 생성 조건과 기본 레이아웃 값을 테스트 가능한 구조로 분리
- Unity Editor 실제 컴파일·EditMode 테스트 결과는 로컬 환경에서 최종 확인 필요

## 결과

기존 평면적인 보드 전투를 거대한 방 중앙의 테이블 게임 형태로 확장했다.

플레이어는 상대와 마주 앉은 구도를 유지하면서 기본 전투 시점, 전체 보드 확인 시점, 상대와 주변 공간을 자유롭게 바라보는 시점을 전환할 수 있다.

향후 최종 카메라·보드·테이블 아트 작업에서 현재 41일차 구조를 기반으로 재질, 조명, 모델 디테일과 연출을 고도화할 수 있는 상태를 마련했다.
