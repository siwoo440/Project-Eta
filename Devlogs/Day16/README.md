# 16일차 개발 일지 — DeckState·HandState 실전 연결 및 손패 숫자키 선택

**날짜**: 2026-09-03  
**목표**: 기존 프로토타입의 손패 직접 삽입 구조를 실제 `DeckState → HandState` 드로우 파이프라인으로 교체하고, 고정 기물 숫자키 선택을 손패 슬롯 1~10 직접 선택 방식으로 변경한다.

## 오늘 한 일

### 1. DeckState 실전 드로우 기능 추가
- `DeckState`에 실제 드로우를 수행하는 API를 추가.
- `OwnedCardPool`을 기준으로 `DrawPile`을 재구성하고 셔플하는 흐름 추가.
- `DrawPile`에서 카드를 한 장 꺼내 손패로 이동시키는 기능 구현.
- 손패가 가득 찬 경우에는 카드를 덱에서 소비하지 않도록 처리해 카드 유실을 방지.

### 2. 프로토타입 시작 카드를 실제 덱 흐름으로 교체
- 기존 `EnsurePrototypeStartingHand()` 호출부는 유지하되 내부 동작을 변경.
- King/Pawn/Knight/Bishop/Rook/Queen 6종을 손패에 직접 넣지 않고 먼저 `OwnedCardPool`에 등록.
- `OwnedCardPool → DrawPile 재구성/셔플 → 초기 5장 드로우` 순서로 시작 상태를 구성.
- 이미 카드 상태가 존재하는 저장/복원 런에서는 시작 카드가 중복 추가되지 않도록 방어.

### 3. 일반 플레이어 턴 자동 드로우 연결
- `TurnManager.TurnChanged` 이벤트와 카드 드로우를 연결.
- 첫 플레이어 턴은 초기 손패 구성과 중복되지 않도록 추가 드로우를 생략.
- 2턴 이후 새로운 `PlayerTurn`이 시작될 때마다 DrawPile에서 카드 1장을 손패로 자동 이동.
- 덱이 비어 있거나 손패가 10장이면 안전하게 드로우를 건너뜀.

### 4. 숫자키 카드 선택 방식을 손패 슬롯 기준으로 변경
- 기존 고정 매핑을 제거:
  - `1 = King`
  - `2 = Pawn`
  - `3 = Knight`
  - `4 = Bishop`
  - `5 = Rook`
  - `6 = Queen`
- 새로운 손패 슬롯 방식으로 변경:
  - `1` = 손패 1번째 카드
  - `2` = 손패 2번째 카드
  - ...
  - `9` = 손패 9번째 카드
  - `0` = 손패 10번째 카드
- 손패 순서가 셔플/드로우 결과에 따라 달라져도 해당 슬롯의 실제 카드를 선택하도록 구성.
- 같은 슬롯을 다시 누르면 카드 선택을 해제할 수 있도록 기존 토글 동작 유지.

### 5. 개발용 카드 상태 표시 갱신
- 기존 King~Queen 고정 카드 목록 대신 현재 실제 `HandState`의 슬롯을 표시하도록 변경.
- 현재 손패 수, DrawPile, OwnedCardPool, DeadCardPile 상태를 개발용 화면에서 확인할 수 있도록 정리.
- 선택된 카드가 어떤 손패 슬롯인지 화면에서 구분할 수 있도록 처리.

### 6. 드로우 덱 저장·복원 보완
- `RunSaveData`에 `drawPileIds`를 추가.
- 저장 시 현재 DrawPile 순서를 PieceId 목록으로 기록.
- 불러오기 시 해당 순서를 다시 `DeckState.DrawPile`에 복원하도록 연결.
- 전투 중 저장 후 다시 불러와도 드로우 순서가 사라지지 않도록 데이터 구조를 확장.

### 7. CardFlow EditMode 테스트 추가
- `CardFlowTests.cs`와 메타 파일 추가.
- 덱 재구성·드로우·손패 상한·시작 카드 구성·손패 슬롯 선택 등 이번 카드 흐름의 핵심 동작을 검증할 테스트를 추가.

## 현재 카드 흐름

```text
기본 6종 시작 카드
        ↓
OwnedCardPool
        ↓
DrawPile 재구성 + 셔플
        ↓
초기 5장 Draw
        ↓
HandState
        ↓
숫자키 1~0으로 손패 슬롯 선택
```

턴 진행 중에는:

```text
PlayerTurn 1
→ 초기 손패만 사용

EnemyTurn
→ 다음 턴

PlayerTurn 2+
→ DrawPile에서 1장 자동 드로우
→ HandState에 추가
```

## 오늘 하지 않은 것

- 5턴 주기 배치 턴 시스템.
- 배치 턴당 신규 기물 1개 제한.
- 손패 카드 1장을 DrawPile 맨 아래로 보내는 정리 기능.
- 사망 기물을 `DeadCardPile`로 보내는 카드 생명주기.
- 라운드 종료 시 생존/사망 카드 복귀 및 덱 재구성.
- 카드 이미지·프레임·아이콘을 사용하는 정식 카드 UI.
- 킹별 서로 다른 시작 카드 풀 구성.
