## 3성 → 4성 합성

3성 기물을 재료로 사용하는 4성 결과 Recipe 20개를 추가했다.

대표 조합은 다음과 같다.

- 전술가 + 돌격대장 → 대장군
- 포병대 + 척탄병 → 대포병
- 사냥꾼 + 매 → 황실기사
- 성기사 + 의무병 → 대성직자
- 유니콘 + 매 → 전쟁기수
- 전차 + 포병대 → 공성전차
- 수호기사 + 성기사 → 수호대장
- 유니콘 + 용마 → 그랜드 유니콘

숨김 Recipe는 다음 두 개다.

- 성기사 + 전술가 → 전장지휘관
- 매 + 유니콘 → 황실기사

유니콘 + 매 → 전쟁기수와 매 + 유니콘 → 황실기사는 같은 두 재료의 A/B 순서로 결과가 달라지므로 87일차에 추가한 방향성 Recipe 구조를 사용한다.

## 4성 → 5성 합성

최종 5성 결과 Recipe 9개를 추가했다.

- 공성전차 + 대포병 → 공성대장
- 대성직자 + 수호대장 → 대성기사
- 전쟁기수 + 황실기사 → 기마장군
- 환술사 + 처형자 → 환영장군
- 대장군 + 전장지휘관 → 황제
- 그랜드 그리폰 + 폭풍기사 → 천공대장
- 대마도사 + 전투치유사 → 대현자
- 철벽기사 + 문지기 → 철벽군주
- 그랜드 유니콘 + 대저격수 → 천공대장 [숨김]

천공대장은 공개 Recipe와 숨김 Recipe 두 개를 가진다.

## 상위 등급 보유·배치 제한

기존 CardOwnershipRules의 상한을 실제 4·5성 데이터에 적용했다.

| 등급 | 동일 카드 보유 상한 | 동일 카드 배치 상한 |
| --- | ---: | ---: |
| 1~3성 | 3 | 제한 없음 |
| 4성 | 2 | 2 |
| 5성 | 1 | 1 |

4성은 동일 기물을 2개까지 합성·보유할 수 있으며 세 번째 결과는 차단된다.

5성은 동일 기물을 1개만 보유할 수 있으며 두 번째 결과는 차단된다.

BoardInputController의 IsWithinDeployLimit도 같은 등급별 상한을 사용해 실제 보드 배치 수를 제한한다.

---
## 상위 등급 이동 규칙

4·5성 PieceDefinition은 고유 능력 프레임워크보다 먼저 실제 배치·이동·기본 공격이 가능하도록 기본 이동 규칙을 연결했다.

- 대장군·황제는 8방향 장거리 이동 사용
- 대포병은 성채형 이동과 스크린 포격 사용
- 황실기사는 기병·카멜·제브라 도약 사용
- 전쟁기수·기마장군은 복수 Rider 이동 사용
- 그랜드 그리폰은 그리폰·역그리폰 복합 이동 사용
- 대저격수는 직선 인접 이동과 최대 8칸 원거리 공격 사용
- 환술사는 기병 → 사제 → 성채 3단계 순환 이동 사용
- 환영장군은 기병 → 사제 → 성채 → 장군 → 척탄병 5단계 순환 이동 사용

회복·오라·상태 이상·소환·피해 변경·장애물·피해 대신 받기 등 고유 효과는 90일차 이후 공통 능력 프레임워크에서 연결한다.

## 5성 임시 수치

기획서에 HP·ATK 임시값이 명시된 다음 4종은 해당 값을 사용했다.

| 기물 | HP | ATK |
| --- | ---: | ---: |
| 황제 | 9 | 8 |
| 천공대장 | 8 | 9 |
| 대현자 | 10 | 6 |
| 철벽군주 | 10 | 7 |

공성대장·대성기사·기마장군·환영장군은 현재 기획서에 HP·ATK 수치가 명시되어 있지 않아 88일차 구현용 테스트 임시값으로 HP 8 / ATK 8을 사용한다.

각 PieceDefinition 설명에도 미확정 테스트 수치임을 표시했다.
