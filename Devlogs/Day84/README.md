# 84일차 : 합성 성장 경로 진단 및 DB 무결성 검증

---
## 개발 목표

현재 1~2성에서 멈춘 합성 콘텐츠를 3~5성으로 확장하기 전에, 등급별 기물·레시피 수와 실제 성장 경로 단절을 F1 패널에서 확인할 수 있는 진단 기반을 추가했다.

기획서의 기물 탭에서 3성 기물 이름·조합·수치가 아직 미확정 상태임을 확인해 임의의 정식 기물은 생성하지 않았다.

---
## 작업 내용

- `FusionProgressionAnalyzer`와 `FusionProgressionReport` 추가
- 1~5성 등급별 플레이어 기물 수 집계 추가
- 2~5성 결과 등급별 유효 합성 레시피 수 집계 추가
- 1성 기물에서 시작하는 실제 합성 결과 도달 가능성 계산 추가
- 첫 누락 기물·레시피·경로 단절 등급 진단 추가
- 기물·레시피 DB 연결 누락 상태 진단 추가
- 중복 ID·중복 재료 조합·규칙 위반·DB 외부 참조 검증 추가
- 중복되거나 잘못된 레시피를 유효 레시피 수에서 제외하도록 수정
- `BoardInputController`에 진단용 데이터베이스 참조 공개 추가
- Battle 씬의 `PieceDatabase` 직렬화 연결 추가
- F1 상태 페이지에 합성 성장 진단 영역 추가

---
## F1 합성 성장 진단

Battle 씬에서 F1을 누르면 상태 페이지에 다음 정보가 표시된다.

| 항목 | 표시 내용 |
| --- | --- |
| 상태 | DB 연결 또는 1~5성 성장 완성 여부 |
| DB 연결 | 기물 DB와 레시피 DB 연결 상태 |
| 기물 | 1~5성 등급별 등록 수 |
| 레시피 | 2~5성 결과 등급별 유효 등록 수 |
| 다음 기물 | 처음으로 등록되지 않은 기물 등급 |
| 다음 레시피 | 처음으로 등록되지 않은 결과 레시피 등급 |
| 경로 단절 | 1성에서 합성으로 도달할 수 없는 첫 등급 |
| 데이터 문제 | 중복·누락·규칙 위반·외부 참조 문제 수 |

현재 프로젝트 데이터는 다음과 같이 진단된다.

```text
기물 1★12 / 2★14 / 3★0 / 4★0 / 5★0
레시피 2★4 / 3★0 / 4★0 / 5★0
다음 기물 3성
다음 레시피 3성
경로 단절 3성
데이터 문제 0
```

---
## 합성 경로 판정

모든 1성 플레이어 기물을 시작 지점으로 등록한 뒤, 현재 도달한 두 재료를 모두 요구하는 레시피의 결과를 반복해서 추가한다.

각 등급에 기물과 레시피가 존재하더라도 1성부터 이어지지 않으면 `1~5성 연결 완료`로 판정하지 않는다.

기물 DB에 등록되지 않은 재료나 결과를 참조하는 레시피와 중복 재료 조합도 정상 성장 경로에서 제외한다.
