## 최종 검증

| 항목 | 결과 |
|---|---|
| PNG·메타·UI 코드 연결 | 45종 확인 |
| Unity Import 설정 | 45종 투명 처리·Clamp·MipMap 비활성 확인 |
| 이미지 메타 GUID | 중복 0개 |
| 실제 프로젝트 EditMode | 859개 통과, 실패 0개 |
| 실제 프로젝트 PlayMode | 3개 통과, 실패 0개 |
| 실제 프로젝트 Windows 개발 빌드 | 성공 |
| 샘플 화면 | 20개 화면 × 2개 해상도, 총 40장 |
| 샘플 해상도 | 1920×1080·2560×1440 |
| Git 변경 공백 검사 | 통과 |

샘플 화면은 실제 UI 생성 코드에 샘플 데이터를 연결한 렌더 결과다. 전체 런을 직접 플레이한 시각 검수와 밸런스 측정은 별도 확인 대상이다. King 초상화와 카드 Artwork는 이번 UI 프레임 제작 범위에 포함하지 않았다.

Unity 검증 실행 중 자동 생성된 성능 테스트 자료와 설정 갱신은 별도로 보관하고 UI 커밋에서 제외했다.
