## 5성 기물별 동작

| 기물 | 적용 내용 |
|---|---|
| 공성대장 | 스크린 1개 포격과 원거리 처치 시 위치 유지 규칙 보존 |
| 대성기사 | 인접 8칸 아군 피해 2 감소, 수호자당 일반 턴 1회 |
| 기마장군 | 라이더 도약 2회 이상 반복 공격 시 피해 +2 |
| 환영장군 | 배치 턴에 시작 형태 선택, 이후 기존 형태 순환 유지 |
| 황제 | 인접 아군 ATK +1 비중첩, 배치마다 부상 인접 아군 1개 HP +1 |
| 하늘원수 | 반복 라이더 공격 피해 +2, 얼룩말 단일 도약 제외 |
| 대현자 | 거리 2 이내 회복 2·적 독 2중첩·아군 다음 피격 피해 1 감소 중 하나 선택 |
| 철벽군주 | 거리 2 이내 아군 피해 최대 2 분담, 자신 HP 1과 대상 최소 피해 1 유지 |

대현자 능력은 일반 행동 1회를 소비한다. 환영장군의 배치 형태 선택은 이동이나 일반 행동을 소비하지 않는다.

황제의 초기 회복은 최초 배치를 마친 첫 플레이어 턴에 적용한다. 주기 배치 회복은 배치 턴 진입 시 적용하며 같은 턴의 중복 이벤트로 다시 발동하지 않는다.
