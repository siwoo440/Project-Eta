## 적 편성 구성

| 전투 종류 | 편성 원형 | 특징 |
|---|---|---|
| 일반 | 전열 | 근접·방어 기물 중심 |
| 일반 | 교란 | 도약·공격 기물 중심 |
| 일반 | 원거리 | 원거리와 전열 혼합 |
| 일반 | 방어 | 방어·지원 기물 중심 |
| 일반 | 혼합 | 역할 혼합과 적 1기 추가 |
| 정예 | 선봉 | 공격·도약 기물 중심 |
| 정예 | 요새 | 방어·지원·원거리 중심 |
| 정예 | 사냥 | 원거리·도약·공격 중심 |

일반·특수 기물은 1~2성만 적 후보로 허용한다. 적 전용 몬스터는 등급과 관계없이 허용하며 왕·합성 전용 기물·보스는 제외한다.
