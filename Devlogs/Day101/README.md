## 구현 범위와 남은 사항

- 15종의 전용 기술·모델·애니메이션은 후속 작업이며 현재 공통 보스 패턴 사용.
- HP·ATK·강화형 수치는 임시값이며 최종 밸런스 미확정.
- 마스터 킹은 데이터만 추가했으며 실제 진입·봉인·진엔딩 전투 미연결.
- 자동 이어하기는 기존 안전 체크포인트 정책 유지, 전투 중 자동 이어하기 미지원.
- 이미 기록된 기존 런의 보스 규칙은 재추첨하지 않으므로 신규 보스 확인은 새 런 기준.
- 실제 화면에서 이동 속도와 HUD 가독성 수동 확인 필요.

## 102일차 개발 방향

쉽게 말하면 지도에서 어떤 길을 고르느냐에 따라 위험과 보상이 달라지고, 이벤트에서 무엇을 얻고 잃었는지 분명하게 보이도록 만드는 작업이다.

추가 100일차로 밀린 기존 일정의 경로·이벤트 작업을 102일차로 이어간다. 기존 이벤트 생성·선택 처리 기반은 유지하면서 기획 이벤트 EV01~EV35를 대조·확장한다. 보스 전용 패턴 제작은 별도 후속 일차로 유지한다.

1. 전투·정예·보상·상점·이벤트의 등장 비중·횟수·연속 제한과 분기 규칙 정리.
2. 기존 이벤트 7개 정의와 기획 EV01~EV35의 대응·누락을 확인한 뒤 선택지·조건·효과 데이터 확장.
3. 이벤트 선택 전 비용·효과 안내와 선택 후 실제 HP·Gold·카드 손익 기록 연결.
4. 같은 Seed의 재현성, 안전 체크포인트 저장 복원, 보상 중복 수령·음수 자원·막힌 경로 검사.

기획서 수치가 없는 부분은 임시 기준을 명시한다. 35종의 완료 여부는 개별 조건·효과·저장·화면 검증 결과로 판정한다.

## 101일차 추가 작업 — 글자와 UI 프레임 정렬

추가 작업 기준: UI 정렬 수정 전 101일차 작업본. 통합 개발 기준은 100일차 커밋 `860abb9`. 2026-10-21 스크린샷의 상태창·입력 안내·보스 체력바 글자 이탈을 실제 Unity UI 생성 코드로 재현한 뒤 수정했다.

- 상태창·보스바·전투 로그·카드 더미 버튼의 Sprite 표시 영역에서 바깥 투명 여백 제외 처리 추가
- 상태창의 비스듬한 모서리 보존과 내부 텍스트 여백·줄바꿈·글자 크기 보정 수정
- 입력 안내의 내부 여백과 두 줄 이상 표시 공간 수정
- 킹 배치 안내가 없을 때 남던 빈 간격을 줄이도록 연속 배치 수정
- 보스 이름과 체력 막대를 중앙 보석 아래의 별도 내부 영역으로 배치 수정
- 긴 보스 이름과 큰 골드 값의 글자 크기 자동 보정 추가
- 전투 로그 탭 높이와 펼침 패널 간격 수정
- 실제 Unity UI의 수정 전·후 화면과 긴 문구 렌더 검증 추가

전체 EditMode 878개·PlayMode 19개 통과. 1920×1080·1464×797·1280×720·1280×1024 UI 렌더와 긴 이름·안내·골드 표시를 확인했다. 독립 검증 화면의 Canvas만 카메라로 렌더한 결과이며 실제 전투 씬 전체를 촬영한 결과는 아니다.

기존 PNG·씬·Prefab 수정과 Inspector 수동 연결 없음. 이번 추가 UI 수정 이후 Windows 실행 파일 빌드는 다시 실행하지 않았다. Unity에서 재생을 중지한 뒤 컴파일 완료 후 다시 시작하면 수정된 런타임 UI가 생성된다.
