## 개발 결과

일반과 정예 전투의 제한 턴·증원 시점을 분리하고, 지도에 안내한 규칙을 실제 전투와 승리 Gold 지급에서 재사용하도록 연결했다. 보상·상점·F1에는 실제 카드 획득 정책과 제외 사유를 표시했다.

정예 전투 수치는 실측 전 임시값이다. 자동 규칙 검사는 실제 전체 런 3회 플레이를 대신하지 않는다.

## 전투와 보상 기준

| 항목 | 일반 | 정예 |
|---|---:|---:|
| 제한 턴 | 30 | 25 |
| 증원 시점 | 3·5턴 | 2·4턴 |
| 1페이즈 승리 Gold | 15 | 25 |
| 페이즈 상승 시 Gold | 페이즈마다 +5 | 페이즈마다 +5 |
| 직접 획득 카드 | 1성 후보 중 1장 | 1성 후보 중 1장 |

중간 보스는 기본 40 Gold, 최종 보스는 기본 60 Gold이며 같은 페이즈 가산 규칙을 사용한다. 기존 보스 전용 패턴은 유지했다. 최종 보스 처치 후에는 카드 보상 없이 런을 종료한다.

2~5성은 합성으로 획득한다. 보유 상한은 사망 카드를 포함하며, 현재 런의 미해금 후보는 영구 해금 후에도 제외하고 다음 런부터 반영한다.

## 저장과 이어하기

규칙을 처음 조회한 스테이지의 제한 턴·시작 적·증원·보스 배치·승리 Gold를 런에 저장한다. 이후 원본 설정이 바뀌어도 이미 저장된 해당 스테이지 규칙을 유지한다.

미조회 스테이지는 최초 조회 시점의 설정을 저장한다. 구버전 저장에 규칙 필드가 없으면 현행 설정으로 채우며, 과거에 저장되지 않았던 규칙을 복구하지는 않는다. 기존 Gold 지급 이력은 유지한다.
