# 17일차 개발 일지 — 자유 배치 턴 및 턴별 카드 소환

**날짜**: 2026-09-03  
**목표**: 전투 시작과 5턴 주기의 배치 턴을 실제 전투 흐름에 연결하고, 플레이어와 적이 각자의 일반 턴에 카드 1장을 행동으로 소환할 수 있도록 턴·입력·UI 구조를 확장한다.

## 오늘 한 일

### 1. 전투 시작을 초기 배치 턴으로 변경
- 기존처럼 기물이 없는 상태에서 바로 `PlayerTurn`으로 시작하지 않도록 전투 시작 상태를 `DeploymentTurn`으로 변경.
- 초기 배치 턴은 일반 턴 수를 소비하지 않고 `TurnNumber = 1`을 대기 상태로 유지.
- 초기 배치가 끝나야 비로소 `1턴 · 플레이어 턴`이 시작되도록 흐름 수정.

### 2. 시작 배치에서 킹 필수 규칙 적용
- 초기 손패에 킹이 셔플 결과와 무관하게 반드시 포함되도록 변경.
- `DeckState.TryMoveSpecificToHand()`를 추가해 특정 카드를 DrawPile에서 손패로 안전하게 이동.
- 시작 배치에서 킹을 놓기 전에는 다른 기물 카드를 먼저 선택·소환할 수 없도록 차단.
- 킹이 보드에 배치되지 않은 상태에서는 배치 턴 종료 입력을 거부.
- 킹 배치 후에는 일반 기물도 계속 자유롭게 추가 배치 가능.

### 3. 자유 배치 턴 구현
- 기존의 `카드 1장 배치 즉시 종료` 방식을 제거.
- 배치 턴 동안 손패가 허용하는 만큼 여러 장의 카드를 자유롭게 소환 가능하도록 변경.
- `TurnManager.DeployedCardCount`로 현재 배치 턴에서 놓은 카드 수를 추적.
- 카드 배치 성공은 배치 수만 등록하며 턴을 자동 종료하지 않음.
- `Space` 입력을 `배치 턴 스킵`이 아니라 명시적인 `배치 턴 종료` 입력으로 변경.

### 4. 5턴 주기 배치 턴 연결
- 일반 전투의 5·10·15·20턴 적 행동이 끝난 뒤 `DeploymentTurn`으로 진입.
- 주기 배치 턴에서는 킹 필수 제한 없이 원하는 손패 카드를 자유롭게 여러 장 배치 가능.
- 아무 카드도 배치하지 않고 `Space`로 바로 종료하는 것도 허용.
- 주기 배치 종료 후 다음 번호의 `PlayerTurn`으로 진행.

### 5. 일반 플레이어 턴 카드 소환 추가
- 기존 이동/공격 외에 손패 카드 1장 소환을 일반 플레이어 행동으로 추가.
- 일반 `PlayerTurn`에서도 숫자키 `1~0`으로 현재 손패 슬롯을 선택 가능.
- 선택한 카드를 아군 10×5 영역의 빈 칸에 소환할 수 있도록 기존 배치 흐름 확장.
- 일반 플레이어 턴에서 카드 소환이 성공하면 해당 소환을 이번 턴의 행동 1회로 처리.
- 카드 소환 직후 즉시 `EnemyTurn`으로 전환해 같은 턴에 이동·공격·추가 소환을 할 수 없도록 처리.
- 보드 기물을 선택하면 기존 카드 선택을 해제해 `이동/공격`과 `카드 소환` 행동을 명확히 분리.

### 6. 적 턴 카드 소환 추가
- 적 전용 프로토타입 `HandState`를 추가.
- 현재 단계에서는 Pawn / Knight / Bishop / Rook / Queen 5종을 적 시작 손패로 구성.
- `EnemyTurn`이 시작되면 적 손패의 첫 카드 1장을 적 10×5 영역의 빈 칸에 자동 소환.
- 적 카드 소환 성공 시 카드 1장을 적 손패에서 제거하고 즉시 적 턴을 완료.
- 적 손패가 비었거나 적 영역에 빈 칸이 없을 때만 기존 더미 적 턴 종료 흐름을 사용.
- 적 진영 자동 소환 위치는 후방부터 빈 칸을 탐색하는 단순 프로토타입 방식으로 구현.

### 7. 일반 턴과 배치 턴의 소환 규칙 분리
- `DeploymentTurn`
  - 원하는 만큼 자유 배치 가능.
  - 배치해도 자동 턴 종료되지 않음.
  - `Space`로 명시적으로 배치 턴 종료.
- `PlayerTurn`
  - 이동 / 공격 / 카드 소환 중 한 가지 행동만 가능.
  - 카드 소환 성공 즉시 `EnemyTurn`.
- `EnemyTurn`
  - 적 카드 소환이 가능하면 카드 1장 자동 소환.
  - 소환 성공 즉시 다음 턴으로 진행.

### 8. 상단 중앙 턴 상태 UI 개선
- 기존 상단 중앙 Canvas UI에 턴별 배경색을 적용.
- 플레이어 턴: 파란색 계열.
- 적 턴: 붉은색 계열.
- 배치 턴: 황금색 계열.
- 승리/패배 상태도 별도 색상으로 구분.
- 텍스트 그림자를 추가해 가독성 보완.
- 시작 배치에서는 `시작 배치 턴 · 킹 배치 필수` 표시.
- 킹 배치 후에는 현재 자유 배치 장수와 `Space 종료` 안내 표시.
- 일반 플레이어 턴에는 `이동/공격/소환 1회`를 표시.
- 적 턴에는 카드 소환 턴임을 표시.

### 9. EditMode 테스트 갱신
- `TurnManagerTests`
  - 초기 배치 턴 시작.
  - 킹 미배치 상태의 턴 종료 차단.
  - 킹 배치 후 명시적 종료 시 1턴 시작.
  - 5턴 주기 배치 진입.
  - 자유 배치 후 명시적 턴 종료.
- `CardFlowTests`
  - 초기 손패 킹 강제 포함.
  - 초기 비킹 카드 선택 차단.
  - 킹 배치 후 추가 자유 배치.
  - 일반 플레이어 턴 카드 소환 후 즉시 적 턴 전환.
  - 적 카드 소환 후 즉시 다음 턴 전환.
  - 배치 턴 카드 소환이 자동으로 턴을 종료하지 않는지 검증.
- `TurnStatusUITests`
  - 킹 필수 초기 배치 문구.
  - 자유 배치 수 표시.
  - 배치 턴 명시적 종료 안내.

## 현재 턴 흐름

```text
전투 시작
↓
초기 배치 턴
├─ 킹 배치 필수
├─ 이후 원하는 카드 추가 자유 배치
└─ Space로 배치 종료
↓
1턴 PlayerTurn
├─ 기물 이동 1회
├─ 공격 1회
└─ 카드 소환 1회
     ↓
   즉시 EnemyTurn
↓
EnemyTurn
├─ 적 카드 1장 자동 소환 가능
└─ 소환 성공 시 즉시 턴 종료
↓
다음 PlayerTurn
```

5턴 주기:

```text
5턴 Player
↓
5턴 Enemy
↓
DeploymentTurn
├─ 원하는 만큼 자유 배치
└─ Space로 종료
↓
6턴 Player
```

## 현재 카드 소환 규칙

```text
PlayerTurn
→ 손패 카드 1장 선택
→ 아군 10×5 빈 칸 소환
→ 손패에서 카드 제거
→ 즉시 EnemyTurn

EnemyTurn
→ 적 손패 카드 1장 선택
→ 적 10×5 빈 칸 자동 소환
→ 적 손패에서 카드 제거
→ 즉시 다음 턴

DeploymentTurn
→ 여러 장 자유 배치
→ 자동 종료 없음
→ Space로 턴 종료
```

## 오늘 하지 않은 것

- 정식 적 AI의 카드 평가·선택 로직.
- 적의 실제 DeckState / DrawPile / DeadCardPile 생명주기.
- 적 카드 상태 저장·복원.
- 소환 카드의 비용·자원 시스템.
- 배치 턴 손패 정리 및 카드 1장을 덱 아래로 보내는 기능.
- 사망 기물을 `DeadCardPile`로 이동시키는 카드 생명주기.
- 라운드 종료 시 카드 풀 복귀 및 덱 재구성.
- 정식 카드 이미지·프레임·손패 Canvas UI.
